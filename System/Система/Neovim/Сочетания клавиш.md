- C-w: Закрывать текущий буфер
- C-o: Открыть файл в новом буфере
- C-q: Выход
- ZZ: Выход и сохранение файла
- Ctrl-S: Сохранить файл
- Esc : Переключиться в режим Вставки

**Клавиши для перемещения:**

- H: Перейти на левый край экрана
- L: Перейти на правый край экрана
- J: Перейти на следующую строку
- K: Перейти на предыдущую строку

для поиска:

- /: Поиск в направлении вправо
- ?: Поиск в направлении влево
- N: Перейти к следующему совпадению
- N: Перейти к предыдущему совпадению
