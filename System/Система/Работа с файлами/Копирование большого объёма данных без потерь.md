Вот три лучших способа сделать это через терминал.

---

### 1. Самый надежный: `rsync` (Рекомендуется)

`rsync` — это стандарт де-факто. Он проверяет целостность данных и позволяет возобновить копирование, если процесс прервется.

Bash

```
rsync -ahP /mnt/storage/yuri/Music /home/yuri/
```

**Разбор флагов:**

- `-a` (archive): Сохраняет права доступа, владельцев и временные метки. Это критично для «отсутствия потерь».
    
- `-h` (human-readable): Выводит размеры в понятных МБ и ГБ.
    
- `-P` (progress + partial): Показывает индикатор выполнения и позволяет продолжить копирование при сбое.
    

> **Важно:** Обратите внимание на слэш в конце `/Music`. Если вы укажете `/Music/`, скопируется только _содержимое_ папки. Без слэша скопируется сама папка `Music`.

---

### 2. Классический: `cp`

Если `rsync` не установлен (хотя в Arch он обычно есть), можно использовать стандартную команду копирования.

Bash

```
cp -axv /mnt/storage/yuri/Music /home/yuri/
```

**Разбор флагов:**

- `-a`: Архивный режим (сохраняет всё).
    
- `-x`: Не выходить за пределы одной файловой системы (полезно, если в папке есть примонтированные диски).
    
- `-v`: Verbose (будет выводить список всех копируемых файлов).
    

---

### 3. С индикатором прогресса: `pv`

Если вы хотите видеть красивый прогресс-бар и скорость передачи данных, можно использовать связку с `tar` и `pv` (нужно установить: `sudo pacman -S pv`).

Bash

```
tar -cf - -C /mnt/storage/yuri/ Music | pv -s $(du -sb /mnt/storage/yuri/Music | cut -f1) | tar -xf - -C /home/yuri/
```

_Это «гиковский» метод, который эффективен при копировании огромного количества мелких файлов._

---

### Что проверить после копирования?

Чтобы на 100% убедиться, что данные идентичны, сравните объем папок:

1. **Проверка размера:**
    
    Bash
    
    ```
    du -sh /mnt/storage/yuri/Music
    du -sh /home/yuri/Music
    ```
    
2. **Проверка количества файлов:**
    
    Bash
    
    ```
    find /mnt/storage/yuri/Music -type f | wc -l
    find /home/yuri/Music -type f | wc -l
    ```
    

### Совет по правам доступа

Поскольку вы копируете из `/mnt/storage` в свой домашний каталог, убедитесь, что владельцем файлов стал ваш пользователь:

Bash

```
sudo chown -R yuri:yuri /home/yuri/Music
```
