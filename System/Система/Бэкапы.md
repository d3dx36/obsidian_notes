# 🛡️ План восстановления Arch Linux с нуля (Установка пакетов, Dotfiles и Автобэкап)

Полное восстановление минималистичной сборки (Niri, Waybar и др.) со всеми программами и темами за 15–20 минут. 

---

## 📥 Шаг 1: Восстановление пакетов на чистой системе

Когда система установлена заново, перенеси файлы списков в домашнюю директорию и выполни:

```bash
# 1. Установка официальных пакетов из репозиториев
sudo pacman -S --needed - < ~/pacman-list.txt

# 2. Установка AUR-пакетов (сначала нужно поставить сам yay)
yay -S --needed - < ~/aur-list.txt
```

## 🗄️ Шаг 2: Резервное копирование и разворачивание конфигов

> [!info] Важно Все настройки лежат в скрытых папках домашней директории. Ключевая папка: `~/.config`.

### Вариант А: Быстрый ручной архив

**Создать архив со всеми темами и конфигами:**

Bash

```
tar -czvf ~/dotfiles-backup.tar.gz ~/.config ~/.gtkrc-2.0 ~/.themes ~/.icons
```

**Распаковать на новой системе:**

Bash

```
tar -xzvf ~/dotfiles-backup.tar.gz -C ~/
```

### Вариант Б: Продвинутый (Git + GNU Stow)

Создай приватный/публичный репозиторий на GitHub/GitLab, залей туда конфиги и клонируй одной командой:

Bash

```
git clone [https://github.com/твой_ник/dotfiles.git](https://github.com/твой_ник/dotfiles.git)
```

## 🕒 Шаг 3: Автоматизация списков пакетов (Systemd-таймер)

Чтобы файлы списков пакетов всегда оставались актуальными, настроен ежедневный экспорт прямо в общую папку с конфигами: `~/.config/backup-lists/`.

> [!abstract] Структура скриптов и служб (Нажми, чтобы развернуть)
> 
> ### 1. Скрипт экспорта (`~/.local/bin/backup-packages.sh`)
> 
> Bash
> 
> ```
> #!/bin/bash
> BACKUP_DIR="/home/yuri/.config/backup-lists"
> 
> pacman -Qqen > "$BACKUP_DIR/pacman-list.txt"
> pacman -Qqem > "$BACKUP_DIR/aur-list.txt"
> echo "Последнее обновление: $(date)" > "$BACKUP_DIR/last-backup.txt"
> ```
> 
> _Не забудь сделать исполняемым: `chmod +x ~/.local/bin/backup-packages.sh`_
> 
> ### 2. Сервис пользователя (`~/.config/systemd/user/backup-packages.service`)
> 
> Ini, TOML
> 
> ```
> [Unit]
> Description=Автоматический бэкап списка пакетов Pacman и AUR
> 
> [Service]
> Type=oneshot
> ExecStart=/home/yuri/.local/bin/backup-packages.sh
> 
> [Install]
> WantedBy=default.target
> ```
> 
> ### 3. Таймер запуска (`~/.config/systemd/user/backup-packages.timer`)
> 
> Ini, TOML
> 
> ```
> [Unit]
> Description=Ежедневный таймер для бэкапа списка пакетов
> 
> [Timer]
> OnBootSec=15min
> OnUnitActiveSec=1d
> Persistent=true
> 
> [Install]
> WantedBy=timers.target
> ```

### Полезные команды управления таймером:

Bash

```
# Перечитать конфигурацию systemd после правок
systemctl --user daemon-reload

# Включить автозапуск таймера при старте системы и запустить прямо сейчас
systemctl --user enable --now backup-packages.timer

# Проверить статус и время следующего срабатывания
systemctl --user list-timers

# Сделать бэкап принудительно прямо сейчас
systemctl --user start backup-packages.service
```

## 🚨 Шаг 4: Аварийное восстановление через Timeshift (Черный экран)

Если система сломалась после обновлений и графическая сессия не загружается:

1. Загрузись с любой **Live-USB флешки Arch Linux**.
    
2. Подключись к интернету и установи Timeshift прямо в Live-режиме:
    
    Bash
    
    ```
    pacman -Sy timeshift
    ```
    
3. Запусти утилиту восстановления в консольном режиме:
    
    Bash
    
    ```
    sudo timeshift --restore
    ```
    
4. Выбери из появившейся интерактивной таблицы нужный снимок (сделанный до поломки), подтверди восстановление разделов и перезагрузи ПК.
