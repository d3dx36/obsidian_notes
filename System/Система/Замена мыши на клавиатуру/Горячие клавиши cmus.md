## 🎵 **Основное управление**

|Клавиша|Действие|
|---|---|
|`c`|**Play/Pause** (воспроизведение/пауза)|
|`x`|**Stop** (остановить воспроизведение)|
|`b`|**Next** (следующий трек)|
|`z`|**Previous** (предыдущий трек)|

|`s`|**Shuffle** (перемешать)|
|`Ctrl` + `s`|**Shuffle album** (перемешать альбом)|

|---|---|
|`add <path>`|Добавить путь в библиотеку|
|`play <file>`|Воспроизвести файл|
|`set <var>=<value>`|Установить настройку|

## 🔧 **Полезные команды настроек**

bash

# В режиме команд (:)
:set output_plugin=pulse      # Аудиовыход PulseAudio
:set replaygain=album         # ReplayGain по альбому
:set continue=true            # Продолжать воспроизведение
:set show_remaining=true      # Показывать оставшееся время
:set autosave=true           # Автосохранение плейлиста

## 💡 **Советы по использованию**

1. **Быстрая навигация**: Используйте `1`-`7` для переключения между представлениями
    
2. **Поиск**: `/` + текст поиска + `Enter`, затем `n` для навигации
    
3. **Очередь**: `y` добавляет в очередь, удобно для временных плейлистов
    
4. **Громкость**: `0`-`9` быстро устанавливают уровень громкости (0=0%, 9=90%)
