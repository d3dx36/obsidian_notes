Вот основные способы управления браузером с клавиатуры:

### 1. Горячие клавиши самого браузера (универсальные)

Это основа, работает в любом браузере (Chrome, Firefox, Brave, Vivaldi и т.д.).

- **Навигация:**
    
    - `Ctrl + T` — новая вкладка
        
    - `Ctrl + W` — закрыть текущую вкладку
        
    - `Ctrl + Shift + T` — открыть последнюю закрытую вкладку
        
    - `Ctrl + Tab` — следующая вкладка
        
    - `Ctrl + Shift + Tab` — предыдущая вкладка
        
    - `Ctrl + [1-9]` — перейти на вкладку по номеру
        
    - `Alt + ←` / `Alt + →` — назад/вперёд по истории
        
- **Поиск и навигация:**
    
    - `Ctrl + L` / `F6` / `Alt + D` — переместить фокус в адресную строку (очень важно!)
        
    - `Ctrl + K` / `Ctrl + E` — переместить фокус в поисковую строку (в некоторых браузерах)
        
    - `Ctrl + F` — поиск на странице
        
    - `F3` / `Enter` — найти следующее совпадение
        
    - `Shift + F3` — найти предыдущее совпадение
        
- **Прокрутка:**
    
    - `Пробел` — прокрутить на один экран вниз
        
    - `Shift + Пробел` — прокрутить на один экран вверх
        
    - `J` / `K` — вниз/вверх (работает в некоторых браузерах, например, с Vimium)
        
    - `Home` / `End` — в начало/конец страницы
        

### 2. Режим просмотра с клавиатуры (Keyboard Navigation)

Практически все современные браузеры имеют встроенный режим, который позволяет перемещаться по ссылкам и кнопкам на странице с помощью клавиатуры.

- **`Tab`** — перемещает фокус между всеми интерактивными элементами (ссылки, кнопки, поля ввода).
    
- **`Shift + Tab`** — перемещает фокус назад.
    
- **`Enter`** — "нажать" на выбранный элемент.
    
- **`Пробел`** — нажать на кнопку или отметить/снять флажок.
    

Это стандартное поведение веб-страниц, но иногда на сложных сайтах переключаться между элементами может быть долго.

### 3. Расширения для навигации в стиле Vim (Настоятельно рекомендую!)

Это **главный инструмент** для комфортной жизни без мыши в браузере под Hyprland. Эти расширения позволяют управлять браузером с помощью клавиш, как в редакторе Vim.

- **Для Chromium-браузеров (Chrome, Brave, Vivaldi, Edge):**
    
    - **Vimium** — классика жанра. Лёгкое и мощное.
        
    - **SurfingKeys** — более продвинутый аналог с большим количеством функций.
        
- **Для Firefox:**
    
    - **Tridactyl** — аналог Vimium для Firefox (очень мощный).
        
    - **Vimium-FF** — порт оригинального Vimium.
        

**Что умеют эти расширения:**

- **Режим "hint"** (самая полезная функция): нажимаешь горячую клавишу (например, `f`), и все кликабельные элементы на странице помечаются буквенными комбинациями. Набираешь комбинацию — и ссылка открывается. Это быстрее мыши!
    
- **Прокрутка:** `J`, `K` для вертикальной прокрутки, `H`, `L` для горизонтальной.
    
- **Закрытие вкладок:** `x`, открытие: `t`.
    
- **Перемещение по истории:** `H` (Back), `L` (Forward).
    
- **Поиск:** `/` для поиска по тексту на странице.
    
- **Копирование ссылок:** `yy` для копирования URL текущей вкладки, `yf` чтобы скопировать URL ссылки через режим hint.
    

### 4. Управление окнами Hyprland

Самое приятное — вы можете seamlessly интегрировать браузер в свой рабочий процесс в Hyprland.

- **Переключение на браузер:** Используйте ваши горячие клавиши для переключения между окнами/рабочими пространствами (например, `Super + [1-9]`).
    
- **Перемещение и ресайз:** Управляйте размером и положением окна браузера стандартными для Hyprland клавишами (например, `Super + ЛКМ` для перемещения, `Super + ПКМ` для ресайза, если вы их не переназначили). Вам даже не нужна мышь для этого — можно использовать стрелки или `hjkl` после зажатия модификатора.
    
- **Создание нового окна:** `Ctrl + N` внутри браузера, а Hyprland автоматически затайлит его согласно вашим правилам.
    

### Пример рабочего процесса:

1. Вы хотите зайти на какой-то сайт.
    
2. Вы уже в браузере (переключились на него по `Super + 2`).
    
3. `Ctrl + L` — фокус в адресную строку.
    
4. Печатаете `habr.com`, `Enter`.
    
5. Видите список статей. Жмёте `f` (если используете Vimium).
    
6. Видите, что все ссылки помечены двухбуквенными кодами. Быстро печатаете код напротив нужной статьи.
    
7. Статья открывается. Читаете, прокручивая страницу `Пробелом` или `J`/`K`.
    
8. Чтобы открыть ссылку в комментариях, снова жмёте `f`, вводите код.
    
9. Закрываете ненужную вкладку нажатием `x`.
    

**Вывод:** Не только можно обойтись без мыши в браузере под Hyprland, но это и **очень удобно и эффективно**. Комбинация встроенных горячих клавиш браузера + расширения типа Vimium + управления окнами Hyprland делает этот процесс быстрым и приятным.

Начните с установки Vimium/SurfingKeys, потратьте 15 минут на запоминание основных комбинаций, и вы уже не захотите возвращаться к мыши.




### Базовое выделение стандартными средствами (работает везде)

- **Перемещение курсора:** Клавиши-стрелки `←`, `→`, `↑`, `↓`.
    
- **Выделение с зажатым Shift:**
    
    - `Shift + ←` / `Shift + →` — выделить по одному символу влево/вправо.
        
    - `Shift + ↑` / `Shift + ↓` — выделить по одной строке вверх/вниз.
        
    - `Ctrl + Shift + ←` / `Ctrl + Shift + →` — выделить по одному слову влево/вправо.
        
    - `Shift + Home` — выделить от курсора до начала строки.
        
    - `Shift + End` — выделить от курсора до конца строки.
        
    - `Ctrl + Shift + Home` — выделить от курсора до начала всего текста.
        
    - `Ctrl + Shift + End` — выделить от курсора до конца всего текста.
        
- **Выделение всего:** `Ctrl + A`.
    

**Процесс:** Установите курсор в начало нужного фрагмента (можно тапать стрелками или кликнуть мышью, это не считается за полноценное использование), затем, удерживая `Shift`, точно "дойдите" стрелками до конца фрагмента.

### 2. Расширения для браузера (как Vimium) — Мощь и точность

Это то, что делает процесс по-настоящему вимиподобным. Например, в **Vimium** и **SurfingKeys** есть специальный **Visual Mode**, почти как в самом Vim.

- **Активация режима выделения:** Обычно клавишей `v`.
    
- **Что происходит:** Вы входите в режим, где можете перемещаться по тексту с помощью `h`, `j`, `k`, `l` (или стрелок), и текст будет выделяться.
    
- **Точное выделение:** Выделение начинается с текущей позиции курсора и следует за вашими движениями.
    
- **Копирование:** После того как вы выделили нужный текст, вы нажимаете `y` (от **y**ank), чтобы скопировать его в буфер обмена.
    
- **Выход из режима:** `Esc`.
    

**Пример в Vimium:**

1. Вы на странице с текстом.
    
2. Жмёте `v` — включается режим выделения.
    
3. Клавишами `j` и `l` спускаетесь вниз и двигаетесь вправо, чтобы выделить нужный абзац.
    
4. Жмёте `y` — текст скопирован.
    
5. Жмёте `Esc` — выходите из режима выделения.
    

Это очень точный и контролируемый метод.

### 3. Поиск + Выделение (Самый быстрый способ для большого текста)

Часто нужно скопировать фрагмент, который вы даже не видите на экране.

1. Используйте поиск по странице: `Ctrl + F` (или `/`, если у вас установлено Vimium-расширение).
    
2. Введите слово или фразу из того места, _возле которого_ нужно начать выделение.
    
3. Нажмите `Enter` — браузер найдет и перейдет к этому слову, установив туда курсор.
    
4. Теперь используйте стандартные методы (`Shift + Стрелки`) или режим `v` в расширении, чтобы выделить текст от этой точки.
    

Это избавляет от долгой прокрутки стрелками до нужного места.

### 4. Использование текстовых элементов страницы

Некоторые сайты (как, например, GitHub или статьи в хороших блогах) позволяют удобно работать с текстом:

- **Тройной клик** (эмуляция клавиатурой): Установите курсор в начало段落 (абзаца) и нажмите `Ctrl + Shift + ↓` — это часто выделяет целую строку или абзац. Поэкспериментируйте.
    

### Итог

Вам **не придется брать мышь** для выделения текста. Процесс выглядит так:

1. **Быстро добраться до места:** С помощью поиска (`/` или `Ctrl+F`) или быстрой прокрутки (`Пробел`, `j`/`k`).
    
2. **Точно позиционировать курсор:** Стрелками или `h`, `j`, `k`, `l`.
    
3. **Включить режим выделения:** Клавишей `v` (в расширении) или зажать `Shift`.
    
4. **Выделить нужный фрагмент.**
    
5. **Скопировать:** `Ctrl + C` или `y` в режиме расширения.
    

Поначалу будет непривычно, но через несколько дней это станет абсолютно естественным и вы оцените, насколько реже вам нужно переключать руки с клавиатуры на мышь и обратно.
