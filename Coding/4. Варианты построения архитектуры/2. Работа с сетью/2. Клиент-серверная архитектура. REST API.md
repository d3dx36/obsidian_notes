- Клиент - тот кто отправляет запросы. На клиенте обычно не хранятся никаких данных кроме кэша
- Сервер  - устройство которое обрабатывает запросы клиента имеет базу данных
- База данных - хранит информацию

## **Структура запроса:**

- **Request line** (строка запроса) — здесь мы определяем тип сообщения (начинается эта строка с _метода_).
- **Header** (заголовок) — здесь у нас находятся дополнительные параметры передачи.
- **Body** (тело сообщения) — оно может быть, а может и отсутствовать.

## **Структура ответа:**

- **Status line** (строка состояния) — здесь передается код ответа (например, 200 — OK, 404).
- **Header** (заголовок) — здесь передаётся дополнительная информация о состоянии ответа, то, что не могло войти в строку состояния.
- **Body** (тело сообщения) — обычно то, что пришло в случае успешного ответа.

Методы 
- **GET** — получить какой-то ресурс.
- **POST** — создать новый ресурс.
- **PUT** — изменить уже имеющийся ресурс.
- **DELETE** — удалить ресурс.
