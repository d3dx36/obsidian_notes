HTTP - данные не шифруются
HTTPS - данные шифруются
Web Socket - применяется когда нужен постояныый обмен данными (мессенджеры, видеочаты, онлайн игры)

### Сравнительная таблица

| **Критерий**           | **HTTP / REST API**                       | **WebSocket**                        |
| ---------------------- | ----------------------------------------- | ------------------------------------ |
| **Модель связи**       | Запрос — Ответ                            | Постоянное двустороннее соединение   |
| **Состояние (State)**  | Stateless (без состояния)                 | Stateful (сохраняет соединение)      |
| **Нагрузка на сервер** | Низкая (освобождает ресурсы)              | Высокая (держит соединение открытым) |
| **Кэширование**        | Поддерживается из коробки (CDN, браузер)  | Нет                                  |
| **Идеально для**       | Загрузки статей, каталогов, профиля, форм | Чатов, игр, котировок, онлайн-карт   |
