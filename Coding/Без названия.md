- **`rememberCoroutineScope`** используется для **событий пользователя (Event-driven)**. Когда действие происходит прямо в момент клика, свайпа или ввода текста (внутри `onClick = { scope.launch { ... } }`).
    
- **`LaunchedEffect(key)`** используется для **реакции на состояние (State-driven)**. Когда код должен зародиться сам при появлении экрана или сработать при выполнении условия/изменении переменной.
