# Стандартные функции Kotlin (Scope Functions)

Все эти функции являются **extension functions**, где объект, на котором они вызываются, называется **receiver**.

## 🛠 Конфигурация и побочные эффекты

### **apply**

_Используется для настройки (конфигурации) объекта._

- **Передает receiver:** через `this` (неявно).
    
- **Возвращает:** сам **receiver**.
    
- **Особенности:** позволяет вызывать методы объекта внутри `{}` без обращения к нему по имени.
    

Kotlin

```
val list = mutableListOf(1, 2).apply {
    add(3)
    sort()
} // Вернет модифицированный list
```

### **also**

_Используется для дополнительных действий (например, логирования), не прерывая цепочку вызовов._

- **Передает receiver:** как аргумент `it`.
    
- **Возвращает:** сам **receiver**.
    

Kotlin

```
val list = mutableListOf(3, 1, 2)
    .also { it.sort() }
    .also { println(it) } // [1, 2, 3]
```

## 🔄 Преобразование и вычисления

### **let**

_Используется для обработки Null-проверок и преобразования объекта._

- **Передает receiver:** как аргумент `it`.
    
- **Возвращает:** результат последней строки лямбды.
    

Kotlin

```
val result = name?.let { "Hey, $it" } ?: "Hey, stranger"
```

### **run**

_Похож на `apply`, но возвращает результат вычисления._

- **Передает receiver:** через `this` (неявно).
    
- **Возвращает:** результат последней строки лямбды.
    

Kotlin

```
val isReady = list.run { size > 0 } // true/false
```

### **with**

_Аналог `run`, но с другим синтаксисом (receiver передается аргументом)._

- **Синтаксис:** `with(obj) { ... }`.
    
- **Совет:** Используйте `run` для лучшей читаемости.

## 🚦 Фильтрация

### **takeIf / takeUnless**

_Проверка условий «на лету»._

- **takeIf:** возвращает **receiver**, если условие `true`, иначе `null`.
    
- **takeUnless:** возвращает **receiver**, если условие `false`, иначе `null`.
    

Kotlin

```
val element = list.takeIf { it.size == 4 }?.get(3)
```

## 📊 Итоговая таблица

|**Функция**|**Доступ к receiver**|**Возвращает**|**Модифицирует receiver**|
|---|---|---|---|
|**apply**|`this`|receiver|Да|
|**also**|`it`|receiver|Нет|
|**let**|`it`|Результат лямбды|Нет|
|**run**|`this`|Результат лямбды|Да|
|**with**|`this`|Результат лямбды|Да|
|**takeIf**|`it`|receiver / null|Нет|

> [!TIP]
> 
> Главное различие: `apply`/`also` всегда возвращают сам объект, а `let`/`run`/`with` — то, что написано в конце блока.
