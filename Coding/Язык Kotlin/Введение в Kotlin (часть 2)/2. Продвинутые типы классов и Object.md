## 1. Enum классы (Enumerated Classes)

Предназначены для хранения фиксированных коллекций констант или типов.

- **Базовое объявление:**
    
    Kotlin
    
    ```
    enum class Weapons { SWORD, DAGGER, STAFF, BOW }
    ```
    
- **Свойства и конструкторы:** Каждая константа может содержать данные.
    
    Kotlin
    
    ```
    enum class Weapons(val profession: String) {
        SWORD("warrior"),
        STAFF("mage");
    }
    ```
    
- **Функции в Enum:** Если в классе есть функции, список констант должен завершаться точкой с запятой `;`.
    
    Kotlin
    
    ```
    enum class Weapons(val profession: String) {
        SWORD("warrior"); // Обязательная точка с запятой
    
        fun getElite(isElite: Boolean) = if (isElite) "elite $profession" else profession
    }
    ```
    

## 2. Sealed классы (Изолированные классы)

Используются для представления ограниченных иерархий классов. В отличие от `Enum`, наследники `sealed` класса могут иметь несколько экземпляров с разным состоянием.

- **Особенности:**
    
    - Являются абстрактными по умолчанию.
        
    - Конструктор приватный.
        
    - Прямые наследники должны быть объявлены в том же файле.
        
- **Преимущество в `when`:** Компилятор проверяет полноту (exhaustiveness), поэтому блок `else` не требуется.
    
    Kotlin
    
    ```
    sealed class Car
    class FastCar(var isFast: Boolean = true) : Car()
    class SlowCar(var isFast: Boolean = false) : Car()
    
    fun check(car: Car) = when (car) {
        is FastCar -> println("Fast")
        is SlowCar -> println("Slow")
        // else не нужен
    }
    ```
    

## 3. Object и Companion Object

### Object (Singleton)

Ключевое слово `object` создает **синглтон** — класс, который имеет только один экземпляр.

- **Ленивая инициализация:** Объект создается только при первом обращении.
    
- Подходит для хранения констант или утилит.
    

Kotlin

```
object Constants {
    val PI = 3.14
}
```

### Companion Object

Используется для реализации «статических» членов класса (в Kotlin нет ключевого слова `static`).

- Привязан к конкретному классу.
    
- У класса может быть только **один** `companion object`.
    
- По умолчанию имеет имя `Companion`, но можно задать собственное.
    

Kotlin

```
class Amigo {
    companion object {
        val tequila = 0.5
    }
}
// Вызов: Amigo.tequila
```

## 4. Анонимные классы (Object Expressions)

Используются для реализации интерфейсов или абстрактных классов «на лету» без создания именованного подкласса.

- **Синтаксис:** `object : InterfaceName { ... }`.
    

Kotlin

```
val shooter = Shooter(object : Gun {
    override fun shoot() { println("KABOOM") }
    override fun reload() { /*...*/ }
})
```

## 🛠 Decompile Kotlin Bytecode

Инструмент для понимания того, как Kotlin-код превращается в Java-код под капотом.

**Как использовать в IntelliJ IDEA / Android Studio:**

1. Нажмите `Shift` дважды (Search Everywhere).
    
2. Введите **"Show Kotlin Bytecode"**.
    
3. В открывшемся окне нажмите кнопку **"Decompile"** в верхней части панели.
    

**Что это дает:**

- **Companion object:** Вы увидите, что это обычный статический вложенный класс с именем `Companion`.
    
- **Sealed classes:** Увидите приватный конструктор и проверку типов в `when` (через `instanceof`).
    
- **Object:** Увидите классическую реализацию Singleton с полем `INSTANCE`.
