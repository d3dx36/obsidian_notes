## 1. Сигнатура класса

Сигнатура включает имя, параметры, родительский класс, интерфейсы и модификаторы доступа.

- **Пример:** `class MyClass(name: String) : ParentClass(), InterfaceA, InterfaceB`.
    
- **Any:** Все классы в Kotlin неявно наследуются от `Any` (аналог `Object` в Java), который имеет методы `equals()`, `hashCode()` и `toString()`.
    

### Модификаторы доступа

|**Модификатор**|**Описание**|
|---|---|
|**public**|Доступен везде. Устанавливается по умолчанию.|
|**internal**|Виден только внутри одного модуля (Gradle/Maven).|
|**private**|Виден только в пределах файла.|
|**inner**|Вложенный класс, имеющий доступ к членам внешнего класса.|

## 2. Наследование и открытость

- **Final по умолчанию:** В Kotlin нельзя наследоваться от обычного класса, так как они помечены как `final`.
    
- **Ключевое слово `open`:** Чтобы разрешить наследование, класс и методы должны быть помечены как `open`.
    
- **Синтаксис:** Используется двоеточие `:` вместо `extends` и `implements`.

## 3. Конструкторы в Kotlin

В Kotlin различают **основной (primary)** и **вторичные (secondary)** конструкторы.

### Основной конструктор

Объявляется сразу в заголовке класса.

Kotlin

```
class User(val name: String, var age: Int) 
```

- Если нужны дополнительные действия при создании, используется блок **`init { ... }`**.
    

### Вторичные конструкторы

Объявляются внутри тела класса через ключевое слово `constructor`. Они должны обязательно вызывать основной конструктор через `this()`.

Kotlin

```
class User(val name: String) {
    var age: Int = 0

    constructor(name: String, age: Int) : this(name) {
        this.age = age
    }
}
```

## 4. Переменные и инициализация

- **`val` (value):** Только для чтения (immutable).
    
- **`var` (variable):** Допускает изменение значения (mutable).
    

### Способы отложенной инициализации

1. **`lateinit var`**: Обещание инициализировать `var` позже (например, в методе `onCreate`). Не работает с примитивами и `nullable` типами.
    
2. **`by lazy`**: Ленивая инициализация `val`. Объект создается только в момент первого обращения к нему.

## 5. Свойства: Геттеры и Сеттеры

Все переменные в Kotlin являются **Properties** (поле + геттер/сеттер по умолчанию).

- **Backing Field (`field`):** Используется внутри геттера/сеттера для обращения к значению поля, чтобы избежать бесконечной рекурсии.
    
    Kotlin
    
    ```
    var name: String = "Bob"
        set(value) { field = value }
    ```
    
- **Backing Property:** Использование скрытой `private` переменной для управления доступом к публичному свойству.

## 6. Делегирование (Delegation)

Позволяет реализовать интерфейс через уже существующий объект с помощью ключевого слова `by`.

Kotlin

```
class Predator(private val animal: Animal) : Animal by animal
```

## 7. Data Classes

Специальные классы для хранения данных.

- **Автоматически генерируют:** `toString()`, `equals()`, `hashCode()`, `copy()` и `componentN()` (для деструктуризации).
    
- **Ограничения:** Должен быть минимум один параметр в конструкторе; параметры должны быть `val` или `var`; класс не может быть `open` или `abstract`.
