## 1. Лямбда-функции

**Лямбда** — это анонимная функция (без имени), которую можно передавать в параметры или присваивать переменным.

- **Базовый синтаксис:** `{ параметры -> тело_функции }`.
    
- **Примеры:**
    
    Kotlin
    
    ```
    val goodMorning = { println("Good morning!") } // Без параметров
    val multiply = { a: Int, b: Int -> a * b }     // С параметрами
    ```
    
- **Возврат значения:** Лямбда возвращает результат последнего выражения в своем теле. Если тело пустое или содержит только `println`, возвращается тип `Unit`.
    
- **Ключевое слово `it`:** Если у лямбды ровно один параметр, его можно не объявлять, а обращаться к нему через `it`.
    

## 2. Функции высшего порядка

Это функции, которые принимают другие функции в качестве аргументов или возвращают их.

Kotlin

```
fun higherOrderFunction(n1: Int, n2: Int, operation: (Int, Int) -> Int) {
   val result = operation(n1, n2)
   println(result)
}
```

- **Вынос лямбды за скобки:** Если лямбда является последним аргументом функции, её можно вынести за круглые скобки: `higherOrderFunction(4, 2) { a, b -> a + b }`.
    

## 3. Захват данных (Closures)

Лямбда-выражение может обращаться к переменным, объявленным вне её области видимости (**замыкание**). В отличие от Java, в Kotlin лямбды могут не только читать, но и **изменять** захваченные переменные (если они объявлены как `var`).

Kotlin

```
var counter = 0
val increment = { counter++ }
increment()
println(counter) // Выведет: 1
```

## 4. Деструктуризация в лямбдах

Если параметром лямбды является объект, поддерживающий деструктуризацию (например, `Pair`, `Map.Entry` или `data class`), можно «разобрать» его на части прямо в объявлении параметров.

Kotlin

```
val map = mapOf("Apple" to 1, "Banana" to 2)

// Деструктуризация записи словаря (key, value)
map.forEach { (name, price) -> 
    println("$name costs $price") 
}
```

_Если какой-то из параметров деструктуризации не используется, его можно заменить нижним подчеркиванием `_`._

## 5. Type Alias (Псевдонимы типов)

Позволяют создавать короткие имена для сложных типов, особенно для сигнатур функций.

- **Синтаксис:** `typealias Имя = Тип`.
    
- **Пример:**
    
    Kotlin
    
    ```
    typealias Operation = (Int, Int) -> Int
    val sum: Operation = { a, b -> a + b }
    ```
    
- Псевдонимы не создают новый тип, а лишь заменяют старый на этапе компиляции.
