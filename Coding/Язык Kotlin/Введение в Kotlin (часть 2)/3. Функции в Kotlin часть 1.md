# Функции в Kotlin

## 1. Объявление и сигнатура

В Kotlin функции объявляются с помощью ключевого слова `fun`. По умолчанию все методы являются `public` и `final`.

|**Характеристика**|**Java**|**Kotlin**|
|---|---|---|
|**С возвращаемым значением**|`int func(int a) { ... }`|`fun func(a: Int): Int { ... }`|
|**Без возвращаемого значения**|`void func() { ... }`|`fun func() { ... }` (возвращает `Unit`)|

- **Тип Unit:** Если тип не указан, функция возвращает объект `Unit`. Это можно проверить, выведя результат вызова такой функции в консоль.
    
- **Модификатор open:** Чтобы разрешить переопределение функции в наследниках, необходимо добавить ключевое слово `open`.
    
- **Named Parameters:** При вызове можно именовать аргументы (например, `printDigits(a = 1, b = 2)`), что позволяет менять их порядок и улучшает читаемость.
    

## 2. Виды функций

### Single-Expression Functions (One line)

Если функция состоит из одного выражения, ее можно записать через `=` без фигурных скобок и явного указания типа возвращаемого значения.

Kotlin

```
private fun sum(a: Int, b: Int) = a + b
```

### Inline Functions

Функции с модификатором `inline` при компиляции подставляют свое тело непосредственно в место вызова.

- **Плюс:** Повышение производительности (особенно при использовании лямбд, так как не создаются лишние объекты анонимных классов).
    
- **Минус:** Увеличение размера итогового байткода из-за дублирования кода.
    

### Noinline и Crossinline

Используются внутри `inline` функций для управления поведением лямбд:

- **`noinline`**: Запрещает инлайнинг конкретной лямбды (для нее будет создан класс).
    
- **`crossinline`**: Запрещает использование нелокальных `return` внутри лямбды, чтобы избежать внезапного выхода из вызывающей функции.
    

## 3. Специфический синтаксис

- **Имена в обратных кавычках:** Можно использовать любые символы в названии, если заключить их в ` ` (клавиша «ё»). Рекомендуется использовать только для юнит-тестов или прототипирования.
    
    Kotlin
    
    ```
    fun `тест проверки суммы`() { ... }
    ```

## 4. Расширения (Extensions)

Kotlin позволяет расширять функциональность существующих классов (даже сторонних библиотек или SDK), не прибегая к наследованию.

### Extension Functions (Функции-расширения)

Позволяют добавить новый метод в класс. Внутри такой функции доступ к объекту осуществляется через ключевое слово `this`.

- **Синтаксис:** `fun ИмяКласса.имяФункции() { ... }`
    
- **Пример:**
    
    Kotlin
    
    ```
    fun String.removeFirstAndLast(): String {
        return this.substring(1, this.length - 1)
    }
    
    // Использование
    val myString = "Hello"
    println(myString.removeFirstAndLast()) // Вывод: ell
    ```
    

### Особенности и ограничения:

1. **Статическое разрешение:** Расширения не изменяют сам класс. При декомпиляции в Java это превращается в статический метод, где экземпляр класса передается первым аргументом.
    
2. **Инкапсуляция:** Расширения не дают доступа к `private` или `protected` членам класса.
    
3. **Конфликты имен:** Если функция-расширение имеет ту же сигнатуру, что и штатный метод класса (member function), приоритет всегда отдается **штатному методу**.
    
4. **Nullable Receiver:** Можно создавать расширения для типов, допускающих null (`ClassName?`). В этом случае внутри функции нужно делать проверку `if (this == null)`.
    

### Extension Properties (Свойства-расширения)

Аналогично функциям, можно добавлять свойства. Они не могут иметь поля (field), поэтому инициализация через `=` невозможна — только через явный `get()`.

Kotlin

```
val String.lastChar: Char
    get() = this[length - 1]
```
