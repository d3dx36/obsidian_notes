## 1. Базовые примитивы

| Тип       | Размер           | Пример                   |
| --------- | ---------------- | ------------------------ |
| `Byte`    | 8 бит            | `val b: Byte = 1`        |
| `Short`   | 16 бит           | `val s: Short = 1000`    |
| `Int`     | 32 бит           | `val i: Int = 42`        |
| `Long`    | 64 бит           | `val l: Long = 42L`      |
| `Float`   | 32 бит           | `val f: Float = 3.14f`   |
| `Double`  | 64 бит           | `val d: Double = 3.14`   |
| `Char`    | 16 бит (Unicode) | `val c: Char = 'A'`      |
| `Boolean` | `true` / `false` | `val ok: Boolean = true` |

Записи числовых литералов:

```kotlin
val hex = 0xFF          // Int
val bin = 0b1010        // Int
val un = 1_000_000      // подчёркивания
val big = 123_456_789L  // Long через L
```

## 2. val vs var

- `val` — неизменяемая ссылка (immutable reference)
- `var` — изменяемая ссылка (type поменять нельзя, только значение)

## 3. Nullable-типы и null-safety

Kotlin не имеет `null` в типах по умолчанию:

```kotlin
var a: Int = 5
// a = null          // ошибка компиляции

var b: Int? = null   // String?, Int?, List<T>? — «nullable»
val len = b?.length  // безопасный вызов -> Int?
val x = b ?: 0       // Elvis-оператор -> Int (non-null)
val y = b!!.length   // утверждает, что b != null (бросит NPE иначе)
```

Цепочка `?.` / `?:`:

```kotlin
val city: String? = user?.address?.city ?: "неизвестно"
```

## 4. Вывод типов (type inference)

Тип можно опустить — компилятор выведет его:

```kotlin
val x = 10          // Int
val y = 3.14        // Double
val list = listOf(1, 2, 3)   // List<Int>
```

Явный тип нужен, когда значение `null` или при перегрузках:

```kotlin
val a: Double? = null
val b: Any = 42
```

## 5. Any и Nothing

- `Any` — базовый тип всех non-null типов; `Any?` включает `null`.

```kotlin
fun show(x: Any) = println(x)
show("a"); show(42); show(3.5)   // всё ок
show(null)   // ошибка — нужно Any?
```

- `Nothing` — тип, который никогда не завершается (используется в `throw`, `return`, Elvis-цепочках).

## 6. Функциональные типы

```kotlin
val f: (Int, Int) -> Int = { a, b -> a + b }
val g: () -> Unit = { println("hi") }
val h: Int.(String) -> Boolean = fun Int.contains(s: String) = true  // extension function type
val i: suspend () -> Unit   // лямбда в корутине
```

## 7. Smart cast

Компилятор сам сужает тип после null-проверки или `is`:

```kotlin
fun len(x: Any) {
    if (x is String) {
        println(x.length)   // x стал String, без as
    }
}

fun f(x: Any?) {
    if (x == null) return
    println(x.length)        // x — non-null Any?
}
```

## 8. Неизменяемые коллекции

```kotlin
val l: List<Int> = listOf(1, 2, 3)
val m: Map<String, Int> = mapOf("a" to 1)
val s: Set<Int> = setOf(1, 2)
val m2: MutableMap<String, Int> = mutableMapOf()
```

`List` — read-only интерфейс (не гарантирует иммутабельность реализации), `List` vs `MutableList` — отдельные типы.

## 9. Typealias

```kotlin
typealias Handler = (String) -> Unit
typealias Pairs = List<Pair<String, Int>>
```

## 10. Важные нюансы

- Целые литералы — всегда `Int`, если не влезает, то `Long`; `Short`/`Byte` не выводятся, нужен явный тип или `.toByte()`.
- Циклы `for (i in 0..10)` — `i` имеет тип `Int`, но при переполнении range возможен `Long`.
- Платформенные типы — Java-типы приходят как `String!` (platform type), их можно присвоить и в `String`, и в `String?`.
- Generic variance: `out T` (копирование, `List<out Animal>`), `in T` (`Consumer<in Dog>`), `*` — star projection.
- Nullability в generic: `List<String?>` ≠ `List<String>`.
