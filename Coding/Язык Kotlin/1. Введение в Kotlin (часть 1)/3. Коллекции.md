Kotlin разделяет коллекции на **изменяемые** (`Mutable`) и **неизменяемые** (`Immutable`) для более строгого контроля исполнения кода.

## Типы коллекций и их создание

|**Тип**|**Неизменяемая (read-only)**|**Изменяемая (mutable)**|
|---|---|---|
|**List**|`listOf<T>()`|`mutableListOf<T>()`|
|**Set**|`setOf<T>()`|`mutableSetOf<T>()`|
|**Map**|`mapOf<K, V>()`|`mutableMapOf<K, V>()`|

### Особенности работы с Map

Для создания пар «ключ-значение» используются:

- **Класс Pair:** `mapOf(Pair("key", 1))`.
    
- **Infix-функция `to`:** `mapOf("key" to 1)` — более лаконичный синтаксис.
    

### Доступ к элементам

Вместо метода `.get(index)` рекомендуется использовать операторные скобки: `list[index]`.

## Операции над списками

### 1. Получение элементов

- **`getOrElse(index) { default }`**: возвращает элемент по индексу или дефолтное значение из лямбды, предотвращая `IndexOutOfBoundsException`.
    
- **`getOrNull(index)`**: возвращает `null`, если индекс вне диапазона.
    

### 2. Фильтрация

- **`filter { predicate }`**: возвращает все элементы, подходящие под условие.
    
- **`drop` / `dropLast`**: отбрасывает N элементов с начала или конца.
    
- **`take` / `takeLast`**: оставляет N элементов с начала или конца.
    
- **`takeWhile`**: прекращает выборку после первого элемента, не подходящего под условие (в отличие от `filter`, который проходит весь список).
    

### 3. Поиск Max/Min

- **`max()` / `min()`**: для базовых типов.
    
- **`maxBy { ... }`**: поиск максимального элемента по конкретному свойству объекта.
    
- **`maxWith(Comparator { ... })`**: поиск с использованием кастомной логики сравнения.
    

### 4. Группировка и уникальность

- **`groupBy { ... }`**: группирует элементы в `Map`, где ключи — параметры сортировки.
    
- **`distinct()`**: удаляет дубликаты, возвращая список уникальных элементов.
    
- **`distinctBy { ... }`**: удаляет дубликаты на основе заданного свойства.
    

### 5. Трансформация

- **`map { ... }`**: преобразует каждый элемент коллекции.
    
- **`flatten()`**: объединяет вложенные коллекции в один плоский список.
    
- **`flatMap { ... }`**: комбинирует `map` и `flatten`.
    

### 6. Условия (Проверки)

- **`any { ... }`**: `true`, если хотя бы один элемент подходит.
    
- **`all { ... }`**: `true`, если все элементы подходят.
    
- **`none { ... }`**: `true`, если ни один элемент не подходит.
    
- **`count { ... }`**: возвращает количество подходящих элементов.
    

### 7. Сортировка

- **`reverse()` / `reversed()`**: разворот списка (первое — для изменяемых, второе — для неизменяемых).
    
- **`sort()` / `sorted()`**: сортировка по возрастанию (первое модифицирует текущий список, второе возвращает новый).
    
- **`shuffle()` / `shuffled()`**: случайное перемешивание.
    

---

## Изменение коллекций

- **Оператор `+` / `-`**: объединение списков или удаление элемента (возвращают новый список).
    
- **`addAll()`**: добавляет все элементы одной коллекции в другую (изменяет текущую).

## Sequences (Последовательности)

`Sequence` — это аналог `Iterable`, который выполняет операции лениво (по требованию).

- **Преимущество:** Избегает создания промежуточных коллекций при цепочке операций.
    
- **Создание:**
    
    - `sequenceOf("A", "B")`.
        
    - `list.asSequence()`.
        
    - `generateSequence(seed) { nextValue }`: генерация последовательности. Должна возвращать `null` для остановки, иначе будет бесконечной.
