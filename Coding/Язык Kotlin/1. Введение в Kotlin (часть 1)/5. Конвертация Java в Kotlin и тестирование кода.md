### 1. Тестирование кода без внедрения в проект

Для экспериментов с логикой, чтобы не загромождать основные классы, в Android Studio/IntelliJ IDEA предусмотрено три инструмента:

|**Инструмент**|**Привязка к проекту**|**Где хранится**|**Особенности**|
|---|---|---|---|
|**Scratch files**|Нет|Вне проекта|Для проверки общей логики, не зависящей от классов проекта.|
|**Worksheets**|Да|Внутри проекта|Есть доступ ко всем классам проекта; не включаются в итоговую сборку.|
|**REPL**|Да|Не сохраняется в файл|Интерактивная консоль для быстрого выполнения строк кода.|

#### Инструкции по запуску:

- **Scratch file:** `File -> New -> Scratch file` -> Выбрать _Kotlin_.
    
- **Worksheet:** `File -> New -> Kotlin Worksheet`.
    
    - _Примечание:_ В Scratches и Worksheets не нужно объявлять метод `main`.
        
- **REPL:** `Tools -> Kotlin -> Kotlin REPL`.
    
    - `Enter` — переход на новую строку.
        
    - `Ctrl + Enter` — выполнение кода.

### 2. Конвертация Java в Kotlin

IDE предоставляет встроенные средства для автоматического перевода кода.

#### Основные способы конвертации:

1. **Конвертация целого файла:**
    
    - Откройте нужный Java-файл.
        
    - Выберите в меню: `Code -> Convert Java File to Kotlin File`.
        
    - Или используйте горячие клавиши: `Ctrl + Alt + Shift + K`.
        
2. **Вставка фрагмента кода:**
    
    - Скопируйте код из Java-файла.
        
    - Вставьте его непосредственно в Kotlin-файл.
        
    - IDE предложит автоматическую конвертацию: нажмите **Yes** в появившемся окне.
        

> [!TIP]
> 
> После автоматической конвертации рекомендуется проверить код на наличие `!!` (not-null assertion) и оптимизировать его под стандарты Kotlin (использование `data class`, `let/apply`, лаконичных конструкций).
