## Объявление переменных

В Kotlin используется два ключевых слова для создания переменных:

- **`val`** — (Value) переменная только для чтения (аналог `final` в Java).
    
- **`var`** — (Variable) изменяемая переменная.
    

### Выведение типов

Если переменной сразу присваивается значение, указывать тип явно не обязательно — Kotlin определит его автоматически.

- Пример: `val numInt = 1` (определится как `Int`).
    

---

## Константы

Для создания констант времени компиляции используется ключевое слово **`const`**.

- **Условие:** Должны быть объявлены на уровне файла (вне класса) или внутри `object`/`companion object`.
    
- В Java аналоги реализуются через `static final` внутри классов.
    

---

## Работа с типами и приведение (Casts)

### Числовые типы

В Kotlin отсутствуют примитивы (как `int`), используются только классы-обертки:

- `Int` (вместо `Integer`), `Float`, `Double`, `Long`.
    
- **Явное приведение:** Выполняется через функции типа `.toInt()`, `.toFloat()`, `.toDouble()`.
    
- **Особенности деления:** Чтобы сохранить остаток, один из операндов должен быть приведен к `Double` или `Float` до выполнения операции.
    
    - `val div = 1 / 2.toDouble()` // Результат: 0.5.
        

### Оператор `as` (Приведение типов)

- **Небезопасное (`as`):** Выбрасывает исключение, если приведение невозможно.
    
- **Безопасное (`as?`):** Возвращает `null`, если приведение не удалось.
    

### Проверка типа (`is`)

Аналог `instanceOf()` в Java:

- `is` — проверка на принадлежность к типу.
    
- `!is` — проверка на непринадлежность к типу.

## Равенство

- **Структурное (`==`):** Проверяет эквивалентность содержимого (аналог `.equals()` в Java).
    
- **Ссылочное (`===`):** Проверяет, указывают ли переменные на один и тот же объект в памяти.
    

---

## Null-Safety (Нулевая безопасность)

По умолчанию переменные в Kotlin не могут принимать значение `null`.

### Типы с поддержкой null

Чтобы разрешить переменной быть `null`, к типу добавляется знак вопроса: `val string: String? = null`

### Инструменты работы с Null

- **Безопасный вызов (`?.`):** Выполняет обращение к свойству/методу, только если объект не `null`. В противном случае возвращает `null`.
    
- **Элвис-оператор (`?:`):** Позволяет задать значение по умолчанию, если выражение слева вернуло `null`.
    
    - `val length = string?.length ?: -1`
        
- **Оператор утверждения (`!!`):** Принудительно обращается к переменной. Если там `null`, выбрасывает `KotlinNullPointerException`.
