## If-else как выражение

В Kotlin `if-else` может возвращать значение, заменяя собой тернарный оператор из Java.

- **Условие:** Для использования в качестве выражения блок `else` обязателен.
    

Kotlin

```
val result = if (a > b) a else b
```

---

## Диапазоны (Ranges) и циклы `for`

Kotlin предлагает лаконичный синтаксис для итерации по интервалам:

- **Прямой порядок:** `for (i in 0..9)` — включает обе границы (0 и 9).
    
- **Исключая последнюю границу:** `for (i in 0 until 10)` — итерация от 0 до 9.
    
- **Обратный порядок:** `for (i in 9 downTo 0)` — используется ключевое слово `downTo`.
    
- **Шаг итерации:** `for (i in 0..9 step 2)` — выполнение с заданным шагом.

## Конструкция `when`

Аналог `switch-case`, обладающий более широким функционалом.

### Основные возможности:

- **Лаконичность:** Не требует оператора `break` после каждого условия.
    
- **Объединение условий:** Несколько значений можно перечислить через запятую: `1, 3, 5 -> println("Odd")`.
    
- **Проверка диапазона:** Использование оператора `in`: `in 0..25 -> println("Low")`.
    
- **Произвольные условия:** Если аргумент не передан в `when`, можно использовать любые логические выражения: `result % 2 == 0 -> ...`.
    

### `when` как выражение

Как и `if-else`, может возвращать значение. В этом случае ветка `else` становится обязательной.

Kotlin

```
val status = when (score) {
    in 90..100 -> "Excellent"
    else -> "Other"
}
```

## Функция `repeat`

Специальная функция для выполнения блока кода заданное количество раз.

- Индекс текущей итерации доступен внутри лямбды (отсчет начинается с **0**).
    

Kotlin

```
repeat(10) { i ->
   println("Итерация №$i") 
}
```



## Функция `forEach`

`forEach` — это функция расширения для коллекций и последовательностей, которая позволяет выполнить блок кода для каждого элемента.

### Ключевые особенности:

- **Синтаксис**: Принимает лямбда-выражение, где текущий элемент доступен через неявное имя `it` (или через явно указанное имя).
    
- **Область применения**: Работает со всеми типами коллекций (`List`, `Set`, `Map`) и `Sequence`.
    
- **Отличие от `for`**: Является функцией высшего порядка, а не языковой конструкцией, что позволяет лаконично встраивать её в цепочки вызовов.
    

### Примеры использования:

**Для списков:**

Kotlin

```
val list = listOf("A", "B", "C")
list.forEach { item ->
    println(item)
}
```

**Для ассоциативных списков (Map):** При итерации по `Map` в лямбду передаются и ключ, и значение:

Kotlin

```
val map = mapOf(1 to "One", 2 to "Two")
map.forEach { (key, value) ->
    println("$key -> $value")
}
```

**Сочетание с индексами (`forEachIndexed`):** Если в процессе итерации нужен индекс элемента:

Kotlin

```
list.forEachIndexed { index, value ->
    println("Элемент под индексом $index имеет значение $value")
}
```
