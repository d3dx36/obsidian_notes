

**Kotlin** — современный статически типизированный язык программирования, работающий поверх JVM.

### Ключевые преимущества

- **Совместимость:** Компилируется в байткод JVM, полностью совместим с библиотеками и фреймворками Java.
    
- **Null-безопасность:** Проверка на `null` происходит на этапе написания кода; IDE предупреждает о необработанных потенциальных `null`-значениях.
    
- **Лаконичность:** Упрощенный синтаксис позволяет писать код быстрее и делать его более читабельным.
    
- **Выведение типов:** Тип переменной определяется автоматически (но может быть указан явно для читаемости или вариантности).

## Сравнение синтаксиса: Java vs Kotlin

### 1. Создание POJO (Data Class)

В Kotlin аналогичный Java-код (с геттерами, сеттерами, `toString`, `hashCode` и `equals`) заменяется одной строкой.

|**Java**|**Kotlin**|
|---|---|
|`public class PojoJava { ... }` (длинный код с полями и методами)|`data class PojoKotlin(private val name: String, private val lastName: String, private val age: Int)`|

### 2. Базовые конструкции

|**Особенность**|**Java**|**Kotlin**|
|---|---|---|
|**Конкатенация**|`"This is " + name + "..."`|`"This is $name..."` (шаблоны строк)|
|**Функции (1 выражение)**|`public int sum(...) { return a + b; }`|`fun sum(a: Int, b: Int) = a + b`|
|**Циклы**|`for(int i = 0; i <= 20; i++)`|`for (i in 0 .. 20)`|

## Основные различия

### Что отсутствует в Kotlin (в привычном виде)

- **Точка с запятой:** В Kotlin не требуется в конце выражений.
    
- **Статичные члены:** Классического ключевого слова `static` нет, используются другие механизмы.
    
- **Примитивы:** Нет ключевых слов `int`, `long`, `byte`. Все типы представлены классами.
    

### Уникальные особенности Kotlin

- **Any:** Базовый класс для всех объектов (аналог `Object` в Java).
    
- **Первичный конструктор:** Объявляется прямо в сигнатуре класса: `class KotlinClass(private val name: String)`.
    
- **First-class citizens:** Функции можно хранить в переменных и передавать как аргументы.
    
- **Управление изменяемостью (Mutability):**
    
    - `val` — неизменяемая переменная (read-only).
        
    - `var` — изменяемая переменная.
        
    - Коллекции разделены на `Mutable` и `Immutable`.
        
    - Все классы по умолчанию являются `final`.
        

> **Важно:** Под капотом Kotlin работает практически так же, как Java. Основное удобство — в автоматизации рутинных задач и безопасности кода.
