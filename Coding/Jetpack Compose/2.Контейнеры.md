Контейнеры нужны что бы исключить перекрытия элементов 

![[Pasted image 20260704184750.png]]

| Контейнер | Описание                           |
| --------- | ---------------------------------- |
| Column    | Располагает элементы вертикально   |
| Row       | Располагает элементы горизонтально |
Для изменения внешнего вида и поведения контейнера используют модификаторы  `Modifiers`

 ## Позиционированию в Jetpack Compose (Row / Column)

| Компонент        | Параметр / Модификатор     | Функция                               | Доступные значения                                                                                                                                        | Влияние на верстку                                                                                           |
| :--------------- | :------------------------- | :------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- |
| **Row**          | `horizontalArrangement`    | Расположение элементов по горизонтали | `Arrangement.Start`<br>`Arrangement.Center`<br>`Arrangement.End`<br>`Arrangement.SpaceBetween`<br>`Arrangement.SpaceEvenly`<br>`Arrangement.SpaceAround`  | Определяет распределение дочерних элементов в строке и свободное пространство между ними.                    |
| **Row**          | `verticalAlignment`        | Выравнивание элементов по вертикали   | `Alignment.Top`<br>`Alignment.CenterVertically`<br>`Alignment.Bottom`                                                                                     | Выравнивает дочерние элементы по верхней границе, по центру или по нижней границе контейнера Row.            |
| **Column**       | `verticalArrangement`      | Расположение элементов по вертикали   | `Arrangement.Top`<br>`Arrangement.Center`<br>`Arrangement.Bottom`<br>`Arrangement.SpaceBetween`<br>`Arrangement.SpaceEvenly`<br>`Arrangement.SpaceAround` | Определяет вертикальное распределение элементов в столбце и расстояние между ними.                           |
| **Column**       | `horizontalAlignment`      | Выравнивание элементов по горизонтали | `Alignment.Start`<br>`Alignment.CenterHorizontally`<br>`Alignment.End`                                                                                    | Выравнивает дочерние элементы по левому краю (началу), центру или правому краю (концу) контейнера Column.    |
| **Row / Column** | `Modifier.fillMaxSize()`   | Размер контейнера                     | От `0.0` до `1.0` (пропорция)                                                                                                                             | Заставляет контейнер занять всё доступное пространство экрана или родительского элемента по ширине и высоте. |
| **Row / Column** | `Modifier.fillMaxWidth()`  | Ширина контейнера                     | От `0.0` до `1.0` (пропорция)                                                                                                                             | Заставляет контейнер растянуться на всю доступную ширину родительского элемента.                             |
| **Row / Column** | `Modifier.fillMaxHeight()` | Высота контейнера                     | От `0.0` до `1.0` (пропорция)                                                                                                                             | Заставляет контейнер растянуться на всю доступную высоту родительского элемента.                             |
