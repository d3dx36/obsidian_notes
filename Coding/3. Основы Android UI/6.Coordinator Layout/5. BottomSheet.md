У нас на очереди **BottomSheet**. Если перевести дословно, то получится нижний листок или листок снизу, в общем, не будем ударяться в лингвистику, давайте к сути. Это нижнее меню, которое вы можете выдвинуть снизу экрана.

Выглядит это вот так:

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/9ea40f529f3dbc8a255f4717e1d550b2/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.5_1.gif)

Это отличное место, чтобы туда убрать дополнительные кнопки управления, или даже засунуть туда `RecyclerView` с каким-нибудь второстепенным списком. Давайте теперь разберём, как это создаётся и как этим управлять.

Чтобы всё это работало, надо в наш **`gradle`** файл модуля `app` добавить зависимость:

implementation 'com.google.android.material:material:1.14.0'

Для начала нам нужно описать в XML-файле саму вёрстку `BottomSheet`, здесь вообще ничего сложного. Создаём любой контейнер с любой вёрсткой, какой только вашей душе угодно, вот, например, код для варианта выше:

<LinearLayout
	xmlns:android="http://schemas.android.com/apk/res/android"
	xmlns:app="http://schemas.android.com/apk/res-auto"
   android:id="@+id/bottom_sheet"
   android:layout_width="match_parent"
   android:layout_height="wrap_content"
   android:background="@android:color/darker_gray"
   android:orientation="vertical"
   app:behavior_hideable="true"
   app:behavior_peekHeight="70dp"
   app:layout_behavior="@string/bottom_sheet_behavior">
	<TextView
       android:layout_width="match_parent"
       android:layout_height="70dp"
       android:background="@color/colorAccent"
       android:gravity="center"
       android:text="Up"
       android:textColor="@android:color/white" />
	<ImageView
       android:layout_width="match_parent"
       android:layout_height="wrap_content"
       android:gravity="center"
       android:scaleType="centerCrop"
       android:src="@drawable/unnamed"
       android:textColor="@android:color/white" />
</LinearLayout>

А теперь давайте разберём, что нужно сделать, чтобы _Android_ понимал, что это у нас `BottomSheet`.

Первое и главное, как и в любом другом элементе `CoordinatorLayout`,  это **поведение**, задаваемое через атрибут `app:layout_behavior="@string/bottom_sheet_behavior"`. Теперь, когда мы разместим его в разметке, он будет знать, как ему себя вести.

Сразу давайте рассмотрим, как задаётся **«язычок»**, за который мы вытаскиваем наше меню. Задаётся он в корневом контейнере атрибутом `app:behavior_peekHeight="70dp"`, в нём мы указываем, насколько наш `BottomSheet` будет торчать в свёрнутом виде.

Соответственно, чтобы было красиво, и место, за которое мы тянем, выглядело подобающим образом, надо на ту высоту, что мы указали в `app:behavior_peekHeight`, сделать и соответствующую вёрстку. В варианте выше у нас есть просто `TextView` с высотой, равной высоте «язычка». Вы можете размещать туда что угодно, главное помните, что эти высоты должны быть равны друг другу (учитывайте внутренние/внешние отступы).

Наш `BottomSheet` готов, осталось только добавить его в верстку нашего `CoordinatorLayout`:

<include layout="@layout/bottom_sheet"/>

Важно, чтобы `BottomSheet` шёл последним элементом, для корректного отображения.

Вот и всё, так легко и непринужденно можно добавить классный элемент _UX_ в свой проект. Давайте посмотрим, что ещё можно сделать с `BottomSheet`.

Этот атрибут позволяет свайпом вниз спрятать наш `BottomSheet`:

## **Управление BottomSheet в коде**

Как показал прошлый пример, нам нужно как-то управлять нашим `BottomSheet` не только при помощи жестов. Для этого есть методы, которые вы можете вызывать в коде.

Вы можете устанавливать **различные состояния** для `BottomSheet`.

Что для этого нужно:

1. Нужно в ваше разметке задать `id` для вашего `BottomSheet`. Если вы найдете его по названию XML-файла, при вызове на нём методов есть большой риск поймать _NPE_, поэтому:
    
    <include layout="@layout/bottom_sheet"
       android:id="@+id/bottom_view"/>
    
2. Теперь нам нужен объект класса `BottomSheetBehaviour`, который и отвечает за все действия с ним, синтаксис такой:
    
    val bottomSheetBehavior = BottomSheetBehavior.from(bottom_view)
    
3. А вот теперь уже можно совершать какие-либо действия. Давайте на нашу `FAB` повесим действие доставания нашего `BottomSheet` после его смахивания с экрана, вот наш слушатель на кнопку:
    
    fab.setOnClickListener {
       bottomSheetBehavior.state = BottomSheetBehavior.STATE_COLLAPSED
    }
    
    Вот так это работает:
    
    ![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/92477d42dca1a1110d9ce76af3b93b13/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.5_3.gif)
    

Вот список методов для управления состоянием:

bottomSheetBehavior.state = BottomSheetBehavior.STATE_COLLAPSED//BottomSheet свернут и есть "язычок"
bottomSheetBehavior.state = BottomSheetBehavior.STATE_EXPANDED//BottomSheet развернут
bottomSheetBehavior.state = BottomSheetBehavior.STATE_HIDDEN//BottomSheet скрыт на экране

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/bc5e082aff1c67bf2a1fb7fe4e1fbd28/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.5_4.gif)

Учтите, что размер указывается в пикселях, поэтому не забудьте конвертировать их в **dp** (например, [здесь](https://angrytools.com/android/pixelcalc/)).

## **BottomSheet callbacks**

Так же как и у любого уважающего себя _View_, у `BottomSheet` есть коллбеки, которые вы можете использовать для своей логики взаимодействия.

Коллбеки также вызываются не на самом _View_, а на экземпляре класса `BottomSheetBehaviour`:

bottomSheetBehavior.addBottomSheetCallback(object: BottomSheetBehavior.BottomSheetCallback() {
   override fun onSlide(bottomSheet: View, slideOffset: Float) {   
   }
   override fun onStateChanged(bottomSheet: View, newState: Int) {    
   }
})

В методе **`onSlide`** мы можем на основании параметра `slideOffset`, который принимает значение от 0 до 1 во `Float`, задавать какую-либо логику, например, менять размер чего-то, скажем, нашей кнопки:

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/4372056f2f5a06febb790be01e84c7e6/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.5_5.gif)

Вот такой будет код для этой анимации:

override fun onSlide(bottomSheet: View, slideOffset: Float) {
   fab.scaleX = 1 - slideOffset
   fab.scaleY = 1 - slideOffset
}

Ну а в методе **`onStateChanged`** вы можете проверить состояния, на основании их совершать какие-то действия. Состояния `BottomSheet` бывают следующие:

BottomSheetBehavior.STATE_COLLAPSED //BottomSheet раскрыт только на peekHeight

BottomSheetBehavior.STATE_DRAGGING //BottomSheet в движении

BottomSheetBehavior.STATE_EXPANDED //BottomSheet раскрыт

BottomSheetBehavior.STATE_HIDDEN //BottomSheet скрыт

BottomSheetBehavior.STATE_SETTLING //BottomSheet автоматически закрывается/раскрывается после того, как вы потянули и отпустили

BottomSheetBehavior.STATE_HALF_EXPANDED //BottomSheet раскрыт наполовину
