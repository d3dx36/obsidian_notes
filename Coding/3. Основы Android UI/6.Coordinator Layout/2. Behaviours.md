## **Scroll-Based**

Начнём с наиболее распространенного типа поведения — **Scroll-Based**. Давайте разберём пример из [прошлого юнита](https://lms.skillfactory.ru/courses/course-v1:SkillFactory+ANDROID-NEW+2020/courseware/83499ae08c7940289bce61275f9ea53f/d901d6f58fa74803b74e6b94f6c888d8/2?activate_block_id=block-v1%3ASkillFactory%2BANDROID-NEW%2B2020%2Btype%40vertical%2Bblock%40df253bd8ebc14e978be4ba5e95db27d6):

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/83a4a045d2e99b8a95e666006c698d7b/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.2_2.gif)

**Что у нас тут есть:**

- `CoordinatorLayout`, как главный контейнер (`CoordinatorLayout behaviour` работает только с _direct children_, то есть только с тем, что в него напрямую вложено, исключение составляет только `NestedScrollView`);
- `AppBarLayout` и `FAB`, как дочерние элементы `CoordinatorLayout`;
- `CollapsingToolbarLayout`, как дочерний элемент `AppBarLayout`.

Код самого XML приводить не буду, он есть у вас в [прошлом юните](https://lms.skillfactory.ru/courses/course-v1:SkillFactory+ANDROID-NEW+2020/courseware/83499ae08c7940289bce61275f9ea53f/d901d6f58fa74803b74e6b94f6c888d8/2?activate_block_id=block-v1%3ASkillFactory%2BANDROID-NEW%2B2020%2Btype%40vertical%2Bblock%40df253bd8ebc14e978be4ba5e95db27d6). Поговорим лучше о двух важных моментах: **`app:layout_scrollFlags`** и **`app:layout_collapseMode`**.

## **layout_ScrollFlags**

Этот атрибут задаётся у `CollapsingToolbarLayout`. Он задаёт тип «схлопывания». Может использоваться один тип, а может и несколько типов одновременно. 

**Важный момент**: флаги комбинируются через **pipe** `|`. Этот символ доступен обычно в английской раскладке и находится зачастую где-то возле клавиши _Enter._

**Давайте посмотрим, какие есть типы:**

**"scroll"**

При скролле вверх _View_ будет убираться, а при скролле вниз — раскрываться, но только когда закончится скролл.

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/43ce2db66219b0395048110cae408891/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.2_3.gif)

**"scroll|enterAlways"**

Похож на `scroll`, но при скролле вниз будет раскрываться независимо от того, дошел ли скролл до конца.

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/43f0bb56913433ade713483134a3ad8f/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.2_4.gif)

**"scroll|exitUntilCollapsed"**

При скролле вверх _Toolbar_ не скроется полностью, при скролле вниз будет раскрываться по достижении конца _View_:

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/7e7e9180db9da723b4b368c37b1d5edd/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.2_5.gif)

## **layout_collapseMode**

Этот атрибут задаёт эффект, который будет применён при сворачивании _View_ при скролле. Их два: `**parallax**` и `**pin**`.

При `**parallax**`  создаётся эффект многоплановости. Как правило, есть смысл его использовать, когда у вас есть картинка:

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/3c88df649f230258016bef0f23f8e830/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.2_6.gif)

Ну а `**pin**` просто сворачивает с той же скоростью, что и скролл:

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/29b04ba8c510f47169cecc320142c0ce/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_27.2_7.gif)
