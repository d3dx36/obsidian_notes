## **Regular top app bar**

Этот вид меню содержит контент и кнопки, которые будут относиться к текущему экрану.

Давайте его создадим. Для этого следует проверить, есть ли у нас нужная зависимость, чтобы использовать компоненты _Material Design_. В файле `**build.gradle**`, который относится к `**module:app**`, указываем следующую зависимость:

implementation 'com.google.android.material:material:1.x.x'

_Актуальную версию вы можете посмотреть на [этой странице](https://maven.google.com/web/index.html#com.google.android.material:material) _Maven_ репозитория._

_Также учтите, что иконки нужно будет добавить в проект самостоятельно или использовать стандартные из папки drawable._

Хорошо, зависимость проверили, если её нет, то добавили. Давайте создадим вёрстку в файле XML:

<androidx.constraintlayout.widget.ConstraintLayout 
   xmlns:android="http://schemas.android.com/apk/res/android"
   xmlns:app="http://schemas.android.com/apk/res-auto"
   xmlns:tools="http://schemas.android.com/tools"
   android:layout_width="match_parent"
   android:layout_height="match_parent"
   tools:context=".MainActivity">

   <com.google.android.material.appbar.AppBarLayout
       android:layout_width="match_parent"
       android:layout_height="wrap_content"
       app:layout_constraintTop_toTopOf="parent">

       <com.google.android.material.appbar.MaterialToolbar
           android:id="@+id/topAppBar"
           android:layout_width="match_parent"
           android:layout_height="?attr/actionBarSize"
           app:title="Skillfactory"
           app:titleTextColor="@android:color/white"
           app:menu="@menu/top_app_bar"
           app:navigationIcon="@drawable/ic_round_menu_24" />

   </com.google.android.material.appbar.AppBarLayout>

</androidx.constraintlayout.widget.ConstraintLayout>

Разберём, что у нас тут происходит. **У нас есть:**

- родительский контейнер `**ConstaintLayout**`;
- контейнер `**AppBarLayout**`, который лежит в `**ConstraintLayout**`;
- и, наконец, сам наш `**MaterialToolbar**`, который мы кладём в `**AppBarLayout**`.

Теперь давайте подробнее разберём атрибуты `**MaterialToolbar**`:

|   |   |
|---|---|
|**Атрибут**|**Описание**|
|`android:id="@+id/topAppBar"`|Это наш _id_, по которому мы можем найти тулбар в коде класса|
|`android:layout_width="match_parent"`|Ширина|
|`android:layout_height="?attr/actionBarSize"`|Высота (здесь указано стандартное значение, вы можете указывать любое под ваши нужды)|
|`app:title="Skillfactory"`|Заголовок|
|`app:titleTextColor="@android:color/white"`|Цвет заголовка|
|`app:menu="@menu/top_app_bar"`|Наше меню, мы его ещё не создали|
|`app:navigationIcon="@drawable/ic_round_menu_24"`|Иконка выезжающего меню (или меню навигации)|

Теперь сделаем само меню. Делается это в отдельном файле, и нам нужна новая папка для ресурсов, давайте её создадим.

Правой кнопкой мыши кликаем папку **res** и создаём новую `**Android resource directory**`:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/9b255e07e4a0344cea80036569f2691a/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_24.2_2.png)

В открывшемся диалоговом окне выбираем `**Resource type** -> **menu**` и нажимаем `**ОК**`:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/62a0d5fa4929f8406ae44f831952d8cd/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_24.2_3.png)

И в этой папке создаем файл `**top_app_bar.xml**` через _New → Menu Resource File,_ в нём будет следующий код:

<menu xmlns:android="http://schemas.android.com/apk/res/android"
   xmlns:app="http://schemas.android.com/apk/res-auto">

   <item
       android:id="@+id/fav"
       android:icon="@drawable/ic_round_favorite_border_24"
       android:title="Избранное"
       app:showAsAction="ifRoom" />

   <item
       android:id="@+id/search"
       android:icon="@drawable/ic_round_search_24"
       android:title="Поиск"
       app:showAsAction="ifRoom" />

   <item
       android:id="@+id/more"
       android:title="More"
       app:showAsAction="withText" />

</menu>

Как мы видим, у нас есть 3 предмета, которые будут **кнопками на нашем Toolbar**. Разберём их атрибуты.

По **`id`** мы будем, как и всегда, искать нашу кнопку. А вот с **`title`** не всё так просто: как вы видите, они у нас везде заданы, но на скриншоте выше никаких заголовков, кроме основного, нет. Так и зачем они нам?

Во-первых, если вы не укажете иконку, то пункт будет отображаться текстом.

Во-вторых, они могут являться своеобразной подсказкой — при долгом нажатии на иконку будет как раз появляться наш заголовок:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/93357f4f836d9898351416e6773549b7/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_24.2_4.gif)

А в-третьих, `title` нам нужны при использовании атрибута **`app:showAsAction`**. О нём стоит поговорить подробно, если вы не укажете этот атрибут, то _AS_ будет ругаться :).

В атрибуте `app:showAsAction` мы указываем, как будут себя вести наши иконки. Как вы заметили, для последнего `item` у нас нет иконки, но тем не менее он представлен тремя точками. Всё потому, что мы указали значение атрибута `app:showAsAction="withText"`, и теперь он будет не иконкой, а выпадающим списком с текстом. Сейчас я задам всем предметам такой атрибут, и получится вот так:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/be7129fd230af979938adb4b0210143e/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_24.2_5.gif)

Хорошо, с этим понятно, но там есть и другие параметры этого атрибута. Вот таблица, в которой указано, что будет происходить со значками при разных параметрах:

|   |   |
|---|---|
|**Параметр**|**Описание**|
|`app:showAsAction="withText"`|Отображение в выпадающем меню текстом|
|`app:showAsAction="ifRoom"`|Отображение на тулбаре, при переполнении будут перемещены в выпадающее меню|
|`app:showAsAction="collapseActionView"`|Является сочетанием `"ifRoom\|withText"`|
|`app:showAsAction="always"`|Всегда показываются на тулбаре|
|`app:showAsAction="never"`|Вообще не показываются|

## **Привязка действий к элементам меню**

Теперь привяжем к нашим кнопкам действия. Делается это, естественно, в коде класса. Тут стоит сказать, что слушателей действий (`ActionListener`) у нас с вами будет целых два! Один будет слушать нажатия на кнопку выезжающего меню, а второй — уже кнопки нашего меню.

Итак, слушатель выезжающего меню задается на нашем `MaterialToolbar.` Ищем его по `id` и вешаем на него слушателя  **`setNavigationOnClickListener`**:

topAppBar.setNavigationOnClickListener {
   Toast.makeText(this, "Когда-нибудь здесь будет навигация...", Toast.LENGTH_SHORT).show()
}

И мы получим:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/8b06ac206e4226385b4ec4f8a3f7d10c/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_24.2_6.gif)

Теперь обработаем наши кнопки меню. Тут нам поможет **`setOnMenuItemClickListener`**. В этом слушателе нам нужно через `when` делать проверку по `id` на то, какая кнопка меню была нажата:

topAppBar.setOnMenuItemClickListener {
   when (it.itemId) {
       R.id.fav -> {
           Toast.makeText(this, "Избранное", Toast.LENGTH_SHORT).show()
           true
       }
       R.id.search -> {
           Toast.makeText(this, "Поиск", Toast.LENGTH_SHORT).show()
           true
       }
       R.id.more -> {
           Toast.makeText(this, "Еще", Toast.LENGTH_SHORT).show()
           true
       }
       else -> false
   }
}

### 5. **Создать Callback для ActionMode**

kotlin

private val actionModeCallback = object : ActionMode.Callback {
    // 4. Создание меню
    override fun onCreateActionMode(mode: ActionMode, menu: Menu): Boolean {
        mode.menuInflater.inflate(R.menu.context_menu, menu)
        mode.title = "Выбрано: 0"
        return true
    }

    // 5. Подготовка меню (опционально)
    override fun onPrepareActionMode(mode: ActionMode, menu: Menu): Boolean {
        return false
    }

    // 6. Обработка кликов по пунктам меню
    override fun onActionItemClicked(mode: ActionMode, item: MenuItem): Boolean {
        when (item.itemId) {
            R.id.action_copy -> handleCopy()
            R.id.action_share -> handleShare()
            R.id.action_delete -> handleDelete()
        }
        mode.finish() // 7. Закрытие CAB
        return true
    }

    // 8. Очистка при закрытии
    override fun onDestroyActionMode(mode: ActionMode) {
        actionMode = null
    }
}

Kotline файл

package com.example.emptyproject  
  
import android.os.Bundle  
import android.view.Menu  
import android.view.MenuItem  
import android.widget.Toast  
import androidx.appcompat.app.AppCompatActivity  
import androidx.appcompat.view.ActionMode  
import com.example.emptyproject.databinding.ActivityMainBinding  
  
class MainActivity : AppCompatActivity() {  
    private lateinit var binding: ActivityMainBinding  
    private var actionMode: ActionMode? = null  
  
    override fun onCreate(savedInstanceState: Bundle?) {  
        super.onCreate(savedInstanceState)  
        binding = ActivityMainBinding.inflate(layoutInflater)  
        setContentView(binding.root)  
  
        binding.textView.setOnLongClickListener {  
            if (actionMode != null) return@setOnLongClickListener false  
  
            actionMode = startSupportActionMode(actionModeCallback)  
            true  
        }  
    }  
  
    private val actionModeCallback = object : ActionMode.Callback {  
        override fun onCreateActionMode(mode: ActionMode, menu: Menu): Boolean {  
            mode.menuInflater.inflate(R.menu.contextual_action_bar, menu)  
            mode.title = "Select option"  
            return true  
        }  
  
        override fun onPrepareActionMode(mode: ActionMode, menu: Menu): Boolean {  
            return false  
        }  
  
        override fun onActionItemClicked(mode: ActionMode, item: MenuItem): Boolean {  
            when (item.itemId) {  
                R.id.photo -> Toast.makeText(this@MainActivity, "photo", Toast.LENGTH_SHORT).show()  
                R.id.android -> Toast.makeText(this@MainActivity, "android", Toast.LENGTH_SHORT)  
                    .show()  
            }  
            mode.finish()  
            return true  
        }  
  
        override fun onDestroyActionMode(mode: ActionMode) {  
            actionMode = null  
        }  
    }  
}
