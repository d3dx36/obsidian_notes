==Явное наследование== 

Для того что бы заново не писать свои темы можно наследоваться от этих тем
- `Theme.MaterialComponents`;
- `Theme.MaterialComponents.NoActionBar`;
- `Theme.MaterialComponents.Light`;
- `Theme.MaterialComponents.Light.NoActionBar`;
- `Theme.MaterialComponents.Light.DarkActionBar`;
- `Theme.MaterialComponents.DayNight`;
- `Theme.MaterialComponents.DayNight.NoActionBar`;
- `Theme.MaterialComponents.DayNight.DarkActionBar`.

Порядок действий открыть файл ==**values/themes.xml**== и прописать:
<resources>  
  
    <style name="MyTheme" parent="Theme.AppCompat.DayNight.DarkActionBar">  
<!--        Здесь же можно переопределить атрибуты наследуемой темы-->  
        <item name="colorPrimary">@color/teal_700</item>  
        <item name="colorPrimaryDark">@color/teal_200</item>  
        <item name="colorAccent">@color/purple_200</item>  
    </style>    
        </resources>


## **Неявное наследование тем**
При таком наследовании тема не наследуется а расширяется
Для этого нужно после названия темы дописать точку и атрибут который нужно наследовать
<resources>  
  
    <style name="MyTheme" parent="Theme.AppCompat.DayNight.DarkActionBar">  
        <!--        Здесь же можно переопределить атрибуты наследуемой темы-->  
        <item name="colorPrimary">@color/teal_700</item>  
        <item name="colorPrimaryDark">@color/teal_200</item>  
        <item name="colorAccent">@color/purple_200</item>  
    </style>  
    <!--        большой текст для проверки-->
    <style name="MyTheme.TextSize">  
        <!--        большой текст для проверки-->  
        <item name="android:textSize">300sp</item>  
    </style>
</resources>

Затем в манифесте прописать
<application
  ...
   android:theme="@style/MyTheme">
	<activity
      ...
       android:theme="@style/MyTheme.TextSize"></activity>
</application>

## Итоговое сравнение:

| Критерий            | Явное       | Неявное                  |
| ------------------- | ----------- | ------------------------ |
| **Контроль**        | Полный      | Ограниченный             |
| **Гибкость**        | Высокая     | Средняя                  |
| **Читаемость**      | Ясная       | Требует знания конвенций |
| **Ошибки**          | Видны сразу | Могут быть скрыты        |
| **Material Design** | Подходит    | Рекомендуется            |

## **ThemeOverlay**

Итак, в нашем примере выше все кнопки синего цвета, потому что у нас задан атрибут `colorPrimary` с таким цветом. Но тут вдруг дизайнерам понадобилось сделать их оранжевыми. Поменять цвет в главной теме мы не можем, потому как другие элементы тоже поменяют свой цвет. Написать свой стиль можно, но это будет долго, и можно где-то ошибиться.

В этой ситуации на помощь нам приходит **`ThemeOverlay`** — специальный класс тем, который позволяет переопределить атрибуты основной темы для какого-то `View`.

Вот такой код мы пишем в файле `styles.xml`:

<style name="MyTheme.NewButton" parent="ThemeOverlay.MaterialComponents">
   <item name="colorPrimary">@android:color/holo_orange_dark</item>
</style>

И применяем его к нашей кнопке в XML:

<Button
   android:id="@+id/button_first"
   android:theme="@style/MyTheme.NewButton"

## **Подключение стилей в тему**

В вашу тему вы можете подключать не только какой-то конкретный атрибут, но и _стиль целиком_, синтаксис тут очень простой:

<item name="android:buttonStyle">@style/RoundButton.OrangeText</item>

То есть здесь указывается не какой-то конкретный атрибут, а ссылка на набор атрибутов. И теперь для всех кнопок будет применён данный стиль, это ещё называется **глобальным стилем**.

## **Ночной режим**

Также его называют **тёмной темой**. Мы рассмотрим два варианта: для устройств с _Android Q (API 29)_ и выше на борту, и для более старых устройств.

Для _API 29_ и выше это просто магия какая-то, достаточно написать одну строчку, и всё случится. Давайте посмотрим:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/7a4767009866be37cd3b3a1b9341c218/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_24.3_6.gif)

Согласитесь, это что-то просто невероятное для одной строки. Вот, кстати, и она. Её нужно добавить в вашу главную тему, то есть тему для всего приложения. По умолчанию это значение `false`:

<style name="MyTheme" parent="Theme.MaterialComponents.Light">
   <item name="android:forceDarkAllowed">true</item>

Но здесь, к сожалению, на данный момент нет гибкости, да и, как говорилось ранее, на более старых версиях ОС это не будет работать.
