Вся отрисовка Custom View происходит внутри переопределяемого метода `onDraw()`:

Kotlin

```
override fun onDraw(canvas: Canvas) {
    // Здесь происходит магия
}
```

- **Canvas (Холст)** — объект, на котором мы рисуем.
    
- **Paint (Краска)** — объект, который задает стиль (цвет, заливка, обводка). **Критически важно:** создавать объекты `Paint` нужно _вне_ метода `onDraw()`, чтобы не нагружать память при перерисовке.
    

Kotlin

```
private var paint = Paint().apply {
   color = Color.RED
   style = Paint.Style.FILL_AND_STROKE
   strokeWidth = 5f
}
```

## 🗺️ Система координат в Android

- **Начало координат (0,0):** Левый верхний угол экрана/View.
    
- **Ось X:** Идет вправо (положительные значения).
    
- **Ось Y:** Перевернута! Идет **вниз** (положительные значения).
    
- _Примечание:_ Координаты могут быть отрицательными, но тогда фигура уйдет за левую или верхнюю границу экрана.
    

## 🛠️ Основные методы отрисовки (Canvas API)

Для получения размеров самого View используются встроенные свойства `width` (ширина) и `height` (высота).

### 1. Заливка фона (`drawColor`)

Закрашивает весь холст одним цветом.

Kotlin

```
canvas.drawColor(Color.MAGENTA)
```

### 2. Точка (`drawPoint`)

Kotlin

```
canvas.drawPoint(width / 2f, height / 2f, paint) // Точка по центру
```

- **Параметры:** `(X, Y, paint)`
    

### 3. Линия (`drawLine`)

Kotlin

```
canvas.drawLine(0f, 0f, width.toFloat(), height.toFloat(), paint) // Диагональ
```

- **Параметры:** `(startX, startY, stopX, stopY, paint)`
    

### 4. Круг (`drawCircle`)

Kotlin

```
canvas.drawCircle(width / 2f, height / 2f, 100f, paint)
```

- **Параметры:** `(centerX, centerY, radius, paint)`
    

### 5. Прямоугольник / Квадрат (`drawRect`)

Kotlin

```
canvas.drawRect(100f, 100f, 300f, 300f, paint)
```

- **Параметры:** `(left, top, right, bottom, paint)` — координаты левого верхнего и правого нижнего углов.
    

## 📐 Сложные и произвольные фигуры (`Path`)

Если нужно нарисовать что-то нестандартное (например, треугольник), используется объект `Path` («путь»), который соединяет точки линиями, а затем «замыкается».

**Пример создания треугольника:**

Kotlin

```
override fun onDraw(canvas: Canvas) {
   val a = Point(0, 0)
   val b = Point(0, 100)
   val c = Point(87, 50)
  
   val path = Path().apply {
       fillType = Path.FillType.EVEN_ODD // Способ заполнения краской
       lineTo(b.x.toFloat(), b.y.toFloat()) // Ведем линию к точке B
       lineTo(c.x.toFloat(), c.y.toFloat()) // Ведем линию к точке C
       lineTo(a.x.toFloat(), a.y.toFloat()) // Возвращаемся к точке A
       close() // Автоматически замыкаем фигуру
   }
   
   canvas.drawPath(path, paint) // Отрисовка пути на холсте
}
```
