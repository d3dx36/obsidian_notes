## 1. Объявление атрибутов в XML

Чтобы кастомное `View` можно было настраивать прямо из XML-разметки, необходимо объявить его атрибуты в ресурсах.

1. В папке `res/values/` создается файл `attrs.xml`.
    
2. Внутри тега `<resources>` создается контейнер `<declare-styleable>`.
    
3. Имя контейнера (`name`) должно строго совпадать с именем класса кастомного View.
    

XML

```
<?xml version="1.0" encoding="utf-8"?>
<resources>
   <declare-styleable name="CustomView">
       <attr name="stroke_width" format="float"/>
   </declare-styleable>
</resources>
```

## 2. Использование View в разметке

После объявления атрибутов кастомный компонент добавляется в layout-файл по полному package-пути:

XML

```
<ru.devivanov.customview.CustomView
   android:id="@+id/custom_view"
   android:layout_width="wrap_content"
   android:layout_height="wrap_content"
   app:stroke_width="5.0"
   app:layout_constraintTop_toTopOf="parent"
   app:layout_constraintBottom_toBottomOf="parent"
   app:layout_
```
