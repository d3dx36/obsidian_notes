## **ItemDecoration**

Для определения отступов каждого элемента списка используется класс `**ItemDecoration**`. Расширив этот класс, можно установить любую логику формирования отступов. К примеру, можно сделать отступы константными, прочитав их из папки `dimens`.

Рассмотрим этот код:

`class ItemOffsetsDecoration(private val context: Context): RecyclerView.ItemDecoration() {`

    `override fun getItemOffsets(outRect: Rect, itemPosition: Int, parent: RecyclerView) {`
        `super.getItemOffsets(outRect, itemPosition, parent)`
        `val hSide = context.resources.getDimension(R.dimen.h_side).toInt()`
        `val vSide = context.resources.getDimension(R.dimen.v_side).toInt()`
        `outRect.set(hSide, vSide, hSide, vSide)`
    `}`
`}`

В данном примере отступы считываются из ресурсов приложения и могут быть адаптированы под разные устройства с помощью **квалификаторов**. Метод `set` вызывается для объекта `Rect` и имеет аргументы внутренних отступов `left`, `top`, `right`, `bottom` (слева, сверху, справа, снизу соответсвенно).

На этом возможности `RecyclerView.ItemDecoration` не заканчиваются. Как насчёт разделителей между элементами или фонового изображения с параллакса? Всё это можно сделать с помощью декоратора, потому что он имеет доступ к **холсту** (**Canvas**) _RecyclerView_.
## **onDraw**

`override fun onDraw(c: Canvas, parent: RecyclerView, state: RecyclerView.State) {`
    `super.onDraw(c, parent, state)`
`}`

Этот метод вызывается перед отрисовкой _View_ из `ViewHolder`. Класс [Canvas](https://developer.android.com/reference/android/graphics/Canvas) реализует холст, на котором можно нарисовать любое графическое изображение. К примеру, картинку для каждого элемента или разделитель между элементами. Чтобы нарисовать на холсте что-либо, необходимо вызвать метод `draw<ГрафическийОбъект>`. Более подробно про метод `draw` и класс `Canvas` вы узнаете в модуле, посвященном _Custom View_.

**Пример 1:**

`override fun onDraw(c: Canvas, parent: RecyclerView, state: RecyclerView.State) {`
    `super.onDraw(c, parent, state)`
    `val paint = Paint() //Создаем кисть для рисования`
    `paint.color = context.getColor(R.color.colorAccent) //Устанавливаем цвет`
    `paint.strokeWidth = 5 F; //Задаем размер кисти 5px`
    `//Рисуем линию из точки (0,0) в точку (100, 100)`
    `c.drawLine(0 f, 0 f, 100 f, 100 f, paint)`
`}`

**Пример 2:**

`val image: Bitmap ? = context.getDrawable(R.drawable.fon) ? .toBitmap()`
`override fun onDraw(c: Canvas, parent: RecyclerView, state: RecyclerView.State) {`
    `super.onDraw(c, parent, state)`
    `image ? .let {`
        `btm - >`
            `c.drawBitmap(btm,`
                `Rect(0, 0, btm.width, btm.height),`
                `Rect(0, 0, btm.width, btm.height), null)`

    `}`
`}`

В данном примере считывается изображение из папки `**drawable**` с названием `**fon**`. В `**onDraw**` вызывается метод `**drawBitmap**`, который как раз отрисовывает изображение.

Также есть метод `onDrawOver`. Его единственное отличие в том, что он вызывается **после того, как отрисовались все View** из `Holder`.

После того как мы определили класс наследник от **RecyclerView.ItemDecoration**, необходимо добавить его в список всех декораторов. Сделать это можно с помощью команды:

recyclerView.addItemDecoration(ItemOffsetsDecoration(this))

К _RecyclerView_ можно добавить сразу несколько `ItemDecoration`. Выполняться они будут в порядке добавления.

## **LayoutAnimation**

`**LayoutAnimation**` позволяет очень легко анимировать каждый элемент списка при первом появлении _RecyclerView_ на экране. Для этого достаточно создать два файла анимации. Первый файл вам уже знаком — это сама анимация или `set` анимаций.

Рассмотрим пример.

**Шаг 1**

Необходимо создать файл анимации в папке `**res/anim**`:

`slide_from_right.xml`

<?xml version="1.0" encoding="utf-8"?>
<set xmlns:android="http://schemas.android.com/apk/res/android"
   android:duration="600">
   <translate
       android:fromXDelta="100%p"
       android:interpolator="@android:anim/decelerate_interpolator"
       android:toXDelta="0" />

   <alpha
       android:fromAlpha="0.5"
       android:interpolator="@android:anim/accelerate_decelerate_interpolator"
       android:toAlpha="1" />
</set>

Данный файл анимации перемещает элемент списка слева направо, параллельно изменяя прозрачность от 0.5 до 1, делая элемент **полностью непрозрачным**.

**Шаг 2**

Теперь в этой же папке создаём `layout_animation`.

`layout_animation.xml`

<?xml version="1.0" encoding="utf-8"?>
<layoutAnimation xmlns:android="http://schemas.android.com/apk/res/android"
   android:animation="@anim/slide_from_right"
   android:animationOrder="normal"
   android:delay="10%" />

Атрибут `**animation**` принимает значение анимации, которую мы создали на прошлом шаге.

Атрибут `**animationOrder**` принимает три варианта на выбор: `normal`, `reverse`, `random`.

Последний атрибут `delay` отвечает за время между стартами анимаций на двух соседних элементах. В данном случае только когда 10% времени первой анимации выполнится, начнётся следующая анимация на следующем элементе.

**Шаг 3**

Теперь осталось только прописать несколько строчек кода в методе `onCreate` класса `MainActivity`:

`val recyclerView = findViewById < RecyclerView > (R.id.recycler_view)`
`//Загружаем анимацию, созданную в XML формате`
`val anim = AnimationUtils.loadLayoutAnimation(this, R.anim.layout_animation)`
`//Передаем ее в recyclerView`
`recyclerView.layoutAnimation = anim`
`//Запускаем анимацию на выполнение`
`recyclerView.scheduleLayoutAnimation()`

Обратите внимание на _комментарии в коде_. Они объясняют, что делает та или иная команда. Готово! Теперь можно запустить программу и посмотреть на результат.

## **ItemAnimator**

Более интересным способом анимаций в _RecyclerView_ является компонент `RecyclerView.ItemAnimator`. С его помощью можно анимировать обновление, добавление, удаление элементов списка. Стоит понимать, что `ItemAnimator` — это просто реализация анимаций с каждым элементом списка при определенных событиях. Сами анимации необходимо прописывать отдельно любым удобным вам способом.

К примеру, можно взять анимации из XML и запустить их на выполнение в `ItemAnimator`. Для этого необходимо переопределить несколько методов, чтобы указать, когда анимация воспроизводится, и сколько она длится. Для начала рассмотрим, какие вообще методы есть в `DefaultItemAnimator` — стандартной реализации `ItemAnimator`.

Методы `DefaultItemAnimator`:

|   |   |
|---|---|
|**Метод**|**Описание**|
|fun onAddStarting(item: RecyclerView.ViewHolder?)|Вызывается, когда в _RecyclerView_ добавляется новый элемент. Чтобы RecyclerView узнал о том, что в адаптер добавился новый элемент, необходимо вызвать `**notifyItemInserted**` для адаптера, передавая позицию вставки.|
|fun getAddDuration(): Long|Возвращает время анимации добавления.|
|fun onChangeStarting(item: RecyclerView.ViewHolder?, oldItem: Boolean)|Вызывается при обновлении данных. Если при этом холдер не изменился, то оба аргумента будут ссылаться на один и тот же объект. Чтобы дать информацию о том, что данные в адаптере изменились, необходимо вызвать `**notifyItemChanged**`, передавая индекс.|
|fun getChangeDuration(): Long|Возвращает время анимации изменения.|
|fun onMoveStarting(item: RecyclerView.ViewHolder?)|Вызывается, когда `ViewHolder` перемещается с одного места на другое. Метод для оповещения `**notifyItemMoved**` принимает 2 параметра — позицию элемента, который начинает перемещаться, и позицию, на которую он перемещается (`**fromPosition**`, `**toPosition**`). Данный метод срабатывает, когда элементы адаптера проходят сортировку или меняются местами.|
|fun getMoveDuration(): Long|Возвращает время анимации.|
|override fun onRemoveStarting(item: RecyclerView.ViewHolder?)|Срабатывает, когда элемент списка удаляется. Метод `**notifyItemRemoved**` для адаптера запускает анимацию из этого метода.|
|fun getRemoveDuration(): Long|Возвращает время анимации.|

В данной таблице представлены основные методы, которые будут использоваться в дальнейшем. Время анимации указывается в миллисекундах, однако лучше получить его из анимации, обратившись к соответствующему полю.

## **Библиотеки аниматоров**

Чтобы сделать красивые анимации добавления/удаления элементов из списка, необходимо реализовать наследника класса `DefaultItemAnimator` и прописать много кода, связанного с анимацией. Однако, можно воспользоваться библиотекой **wasabeef**. Разработчики этой библиотеки написали очень много классных аниматоров и, чтобы использовать их в своем проекте, необходимо прописать всего пару строчек.

[Ссылка на библиотеку wasabeef](https://github.com/wasabeef/recyclerview-animators).

На странице этой библиотеки есть вся необходимая информация и даже примеры анимаций, так что не придётся долго копаться в коде.

Главной особенностью библиотеки [wasabeef](https://github.com/wasabeef/recyclerview-animators) является то, что она предоставляет возможности анимировать содержимое `ViewHolder`.
