В этом юните мы подробнее разберём тему **событий** в _RecyclerView_. Чтобы _RecyclerView_ узнал о том, что с данными в адаптере что-либо произошло, необходимо для адаптера вызвать соответствующий метод `notify<**Событие>**`,  где:

- `ItemChanged(<Индекс элемента>)` — данные для этого элемента **обновились**;
- `ItemInserted(<Позиция вставки>)` — новый элемент **появился** в списке;
- `ItemRemoved(<Позиция удаления>)` — элемент **удалился** из списка
- `ItemMoved(<Позиция>,<Новая позиция>)` — элемент **переместился**.

Также стоит обратить внимание на метод `**notifyDataSetChanged**`. Этот метод заставляет весь _RecyclerView_ перерисовываться. Это приводит к ухудшению производительности и мерцанию всех элементов. Чтобы этого избежать, необходимо использовать **StableIds**.

## **StableIds**

Мы часто сталкиваемся со случаем, когда мы внесли несколько изменений в наш набор данных _RecyclerView_ и хотим уведомить адаптер об изменениях, вызвав `**notifyDataSetChanged()**` на адаптере. Но это приводит к тому, что _RecyclerView_ мерцает, что более заметно, если у вас есть изображения внутри ваших `ViewHolder`. Это происходит потому, что адаптер делает недействительным весь набор данных **RecyclerViewPool** и создает их все снова.

Этого можно избежать, используя **StableIds**. Это уникальные идентификаторы, представляющие определенный элемент данных внутри вашего адаптера. По умолчанию _StableIds_ отключены в `**RecyclerView.Adapter**`, что заставляет адаптер воссоздавать каждое представление при вызове функции `**notifyDataSetChanged()**`. При включенном _StableIds_ адаптер знает, какие элементы следует пересоздать, а какие сохранить, тем самым предотвращая мерцание.

Для этого вызовите `**setHasStableIds(true)**` на вашем адаптере и переопределите `**getItemId(int position)**`, чтобы вернуть уникальный идентификатор, который будет представлять каждый элемент данных.

В классе _RecyclerView_ можно наткнуться на перегруженную версию метода привязки `ViewHolder`, она выглядит так:

fun onBindViewHolder(VH, Int, List<Object>)

Класс `RecyclerView.Adapter` предоставляет перегруженный метод `notifyItemChanged(int, Object)`, в котором мы можем отправить объект `**payload**` вместе с позицией элемента.

**Payload —** это объект, описывающий, какие данные изменились**.**

Перед вызовом `onBindViewHolder (VH holder, int position)` адаптер вызывает перегруженный `onBindViewHolder` и передаёт ему эти объекты `payload` в виде списка.

Мы можем проверить, пуст ли этот список, чтобы узнать, был ли отправлен `payload`. Если `payload` был отправлен, то мы можем обновить только те части нашего `ViewHolder`, которые, как мы знаем, изменились. В противном случае, мы просто вызываем супер метод, который затем вызывает базовый `**onBindViewHolder()**`.

`В адаптере:`

override fun onBindViewHolder(holder: ViewHolder, position: Int) {
    holder.icon.setImageResource(data[position].idIcon)
    holder.textName.text = data[position].name
    holder.textDesc.text = data[position].desc
}

override fun onBindViewHolder(holder: ViewHolder, position: Int, payloads: MutableList < Any > ) {
    if (payloads.isEmpty())
        super.onBindViewHolder(holder, position, payloads)
    else {
        payloads.find {
                it is String && it == "icon"
            }
            .let {
                holder.icon.setImageResource(data[position].idIcon)
            }
        payloads.find {
                it is String && it == "name"
            }
            .let {
                holder.textName.text = data[position].name
            }
        payloads.find {
                it is String && it == "desc"
            }
            .let {
                holder.textDesc.text = data[position].desc
            }
    }
}

override fun getItemId(position: Int): Long {
    return data[position].hashCode().toLong()
}

`MainActivity.kt метод OnCreate`:

val recycler = findViewById < RecyclerView > (R.id.recycler_view)
recycler.adapter = adapter
//Включаем StableIds
adapter.setHasStableIds(true)
//Изменилась иконка
adapter.data[0].idIcon = R.drawable.ic_banana
//Оповещаем RecyclerView об изменениях, используя payload
adapter.notifyItemChanged(0, "icon")

В данном примере перегруженная версия `onBindViewHolder` пытается найти в списке `payloads` строки, которые говорят о том, какое поле объекта изменилось. Если `payloads` пустой, значит весь объект изменился и вызывается обычный метод `onBindViewHolder`. Также обратите внимание на метод `**getItemId**`, с помощью него реализуется работа _StableIds_. С включенным _StableIds_ адаптер будет вызывать перерисовку только для объектов, которые действительно изменились. С появлением **DiffUtil** необходимость в использовании _StableIds_ полностью отпала.

## **DiffUtil**

**DiffUtil** — это класс, который позволяет адаптеру автоматически определять, какие ячейки списка необходимо обновить. Это очень удобно, так как нам не нужно следить на индексами элементов и думать о производительности. **DiffUtil** с помощью математических умных алгоритмов сделает всю работу за нас, используя точечные вызовы метода `**notify**`. От нас только требуется реализовать `**DiffUtil.Callback**`, вычислить `Diff` и сообщить об этом адаптеру.

Рассмотрим, какие методы необходимо реализовать в `**DiffUtil.Callback**` и за что они отвечают:

|   |   |
|---|---|
|**Метод**|**Описание**|
|override fun getOldListSize(): Int|Возвращает количество элементов в старом списке|
|override fun getNewListSize(): Int|Возвращает количество элементов в новом списке|
|override fun areItemsTheSame(oldItemPosition: Int, newItemPosition: Int): Boolean|Возвращает правду, если оба элемента одинаковые|
|override fun areContentsTheSame(oldItemPosition: Int, newItemPosition: Int): Boolean|Возвращает правду, если содержимое элементов списка одинаковое|

Рассмотрим, как использовать _DiffUtil**,**_ на примере.

Класс данных:

class Product(val id: Int, @DrawableRes var idIcon: Int, val name: String, val desc: String)

Тут есть `**id**` — идентификатор уникальности данного продукта, `**idIcon**` — ссылка на картинку в формате `R.drawable.<**idIcon**>`, `**name**` — наименование продукта и `desc` — описание.

Данные типа `Product` устанавливаются в адаптер. Наша задача реализовать способ оповещения изменения данных в адаптере через _DiffUtil_.

**Шаг 1:** Создать реализацию `DiffUtil.Callback`.

`ProductDiff.kt`

class ProductDiff(val oldList: ArrayList < Product > , val newList: ArrayList < Product > ): DiffUtil.Callback() {
    override fun getOldListSize(): Int {
        return oldList.size
    }

    override fun getNewListSize(): Int {
        return newList.size
    }

    //Элементы одинаковые
    override fun areItemsTheSame(oldItemPosition: Int, newItemPosition: Int): Boolean {
        return oldList[oldItemPosition].id == newList[newItemPosition].id
    }

    //Содержимое одинаковое
    override fun areContentsTheSame(oldItemPosition: Int, newItemPosition: Int): Boolean {
        val oldProduct = oldList[oldItemPosition]
        val newProduct = newList[newItemPosition]
        return oldProduct.name == newProduct.name &&
            oldProduct.desc == newProduct.desc &&
            oldProduct.idIcon == newProduct.idIcon
    }
}

Самое важное из этого кода: элементы одинаковые, если их `id` равны, и содержимое элементов одинаковое, если все поля объектов равны. Индексы каждого элемента передаются в аргументах. Старый и новый список передаются в конструкторе класса реализации `**DiffUtil.Calback**`.

**Шаг 2**: Вычислить `Diff` и получить `**DiffResult**`:

recyclerView.adapter = adapter
val diff = ProductDiff(adapter.data, newData)
val diffResult = DiffUtil.calculateDiff(diff)

При вызове метода `**calculateDiff**` происходит сравнение двух списков и результат записывается в объект типа `**DiffResult**`.

**Шаг 3:** Обновить данные и оповестить об этом _RecyclerView:_

adapter.data = newData
diffResult.dispatchUpdatesTo(adapter)

На этом шаге мы передаём в адаптер новые данные и просим `**diffResult**` обновить _RecyclerView_ с учётом изменений. То есть это будет именно использование `notify` методов, чтобы обновить список максимально эффективно, **без лишних вызовов отрисовки**.
