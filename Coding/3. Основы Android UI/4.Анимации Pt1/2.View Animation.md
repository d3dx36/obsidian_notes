
Эти атрибуты применяются к элементам `<set>`, а также к отдельным элементам преобразований.

| Атрибут                | Тип        | Описание                                                                                                                                       |
| ---------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `android:duration`     | `integer`  | Продолжительность анимации в миллисекундах. **(Обязательный для преобразований)**                                                              |
| `android:startOffset`  | `integer`  | Задержка в миллисекундах перед началом анимации. Полезно для последовательных анимаций.                                                        |
| `android:fillAfter`    | `boolean`  | Если `true`, View **сохранит** состояние, достигнутое в конце анимации. Если `false`, View вернется в исходное состояние.                      |
| `android:fillBefore`   | `boolean`  | Если `true`, View будет находиться в состоянии, определенном началом анимации, до ее фактического старта.                                      |
| `android:repeatCount`  | `integer`  | Количество повторений анимации. `-1` означает бесконечное повторение.                                                                          |
| `android:repeatMode`   | `keyword`  | Определяет поведение при повторении. Может быть `repeat` (перезапуск с начала) или `reverse` (обратное воспроизведение).                       |
| `android:interpolator` | `resource` | Интерполятор, который определяет скорость изменения анимации с течением времени. Например: `@android:anim/accelerate_decelerate_interpolator`. |

## Атрибуты для конкретных типов преобразований

Каждый из четырех типов преобразований имеет свои уникальные атрибуты, которые определяют начальные и конечные значения.

## 1. Изменение прозрачности (Alpha Animation) - `<alpha>`

|Атрибут|Тип|Описание|
|---|---|---|
|`android:fromAlpha`|`float`|Начальный уровень прозрачности (от `0.0` - полностью прозрачный, до `1.0` - полностью непрозрачный).|
|`android:toAlpha`|`float`|Конечный уровень прозрачности (от `0.0` до `1.0`).|

---

## 2. Масштабирование (Scale Animation) - `<scale>`

|Атрибут|Тип|Описание|
|---|---|---|
|`android:fromXScale`|`float`|Начальный коэффициент масштабирования по оси X. `1.0` — исходный размер.|
|`android:toXScale`|`float`|Конечный коэффициент масштабирования по оси X.|
|`android:fromYScale`|`float`|Начальный коэффициент масштабирования по оси Y.|
|`android:toYScale`|`float`|Конечный коэффициент масштабирования по оси Y.|
|`android:pivotX`|`percentage`, `float`|X-координата точки, относительно которой происходит масштабирование. Может быть абсолютным значением (в пикселях), относительным к самому View (например, `50%`) или относительно родителя (`50%p`).|
|`android:pivotY`|`percentage`, `float`|Y-координата точки, относительно которой происходит масштабирование.|

---

## 3. Перемещение (Translate Animation) - `<translate>`

Вместо явных координат используются _дельты_ (смещения) относительно начальной позиции.

|Атрибут|Тип|Описание|
|---|---|---|
|`android:fromXDelta`|`percentage`, `float`|Начальное горизонтальное смещение. Может быть абсолютным значением, относительным к самому View (`50%`) или относительно родителя (`50%p`).|
|`android:toXDelta`|`percentage`, `float`|Конечное горизонтальное смещение.|
|`android:fromYDelta`|`percentage`, `float`|Начальное вертикальное смещение.|
|`android:toYDelta`|`percentage`, `float`|Конечное вертикальное смещение.|

---

## 4. Вращение (Rotate Animation) - `<rotate>`

|Атрибут|Тип|Описание|
|---|---|---|
|`android:fromDegrees`|`float`|Начальный угол вращения в градусах.|
|`android:toDegrees`|`float`|Конечный угол вращения в градусах.|
|`android:pivotX`|`percentage`, `float`|X-координата точки, относительно которой происходит вращение. (Как и для `<scale>`).|
|`android:pivotY`|`percentage`, `float`|Y-координата точки, относительно которой происходит вращение.|

---

## Контейнер анимаций (Animation Set) - `<set>`

Элемент `<set>` используется для объединения других анимаций (`<alpha>`, `<scale>`, `<translate>`, `<rotate>`) в группу.

|Атрибут|Тип|Описание|
|---|---|---|
|`android:shareInterpolator`|`boolean`|Если `true`, то интерполятор, установленный в `<set>`, будет использоваться всеми дочерними элементами, которые явно не определяют свой собственный интерполятор. По умолчанию `true`.|
|_Общие атрибуты_||`<set>` также поддерживает все **общие атрибуты** (`duration`, `startOffset`, `fillAfter` и т. д.).|

**Примечание:** View Animation не меняет фактические границы или положение View. Она только меняет _отрисовку_ View. Например, если вы перемещаете кнопку, она будет выглядеть перемещенной, но область, в которую нужно нажать, останется на исходном месте. Для более сложных и современных анимаций, которые меняют фактические свойства объекта, рекомендуется использовать **Property Animation** (Анимация свойств).
