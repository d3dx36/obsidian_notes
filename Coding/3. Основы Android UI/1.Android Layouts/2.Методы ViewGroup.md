|                                       |                                                    |
| ------------------------------------- | -------------------------------------------------- |
| **Сигнатура метода**                  | **Описание работы**                                |
| fun getChildAt(index: Int): View?     | Возвращает элемент по индексу                      |
| fun addView(child: View?)             | Добавляет элемент в конец контейнера               |
| fun addView(child: View?, index: Int) | Добавляет элемент в позицию `index`                |
| fun removeView(view: View?)           | Удаляет `**view**` из контейнера                   |
| fun removeViewAt(index: Int)          | Удаляет `**view**` из контейнера в позиции `index` |
| fun removeAllViewsInLayout()          | Удаляет все `view` из контейнера                   |
