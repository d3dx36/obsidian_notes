**View** — это класс, который представляет собой основной блок для создания компонентов пользовательского интерфейса. Все элементы _UI_ унаследованы от этого класса. Представлен он пустой прямоугольной областью на экране, которая отвечает за отрисовку интерфейса и обработку событий.

Вот так выглядит `TextView` в файле разметки:

<TextView
   android:layout_width="wrap_content"
   android:layout_height="wrap_content"
   android:layout_gravity="center"
   android:text="Hello World!" />

Вот то же самое, но исполнено кодом:

val textView = TextView(this)
textView.apply {
   text = "Hello World!"
   gravity = Gravity.CENTER
}

main_container.addView(textView)

Бывают случаи, когда такой подход оправдан. Скорее всего вы не будете создавать так ваши `View`, но свойства вашего `View` вы будете менять в коде гарантированно. Например, по какому-то условию менять цвет текста:

val a = 0
val b = 1

if (a > b) {
   text_View_hello.setTextColor(ContextCompat.getColor(this, R.color.colorAccent))
} else {
   text_View_hello.setTextColor(ContextCompat.getColor(this, R.color.colorAccent))
}

## **Custom View**

Как вы верно поняли, если различных `View` так много, то это потому, что их можно **создавать самому**. Существует два глобальных способа создать свой `View`. 

**1 способ**

Создание `View` с нуля, унаследовав её от класса `View`. В этом случае все элементы вашего `View` надо создавать с нуля, вот, к примеру, кастомный `View`-спидометр:

![рисунок](https://lms-cdn.skillfactory.ru/assets/courseware/v1/efac2ef8b2b6f4ed9c422ccff6cc7a77/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_23_speed.png)

Всё, что вы видите, описано в коде, каждая отрисовка графического элемента задана программно. За исключением наверно только текста, тут вы просто подключаете шрифт.

**2 способ**

Вы можете свой `View` унаследовать от уже имеющегося `View`. Например, `ImageButton` создан на основе `ImageView`:

public class ImageButton extends ImageView {
  public ImageButton(Context Context) {

То есть, как и в случае с наследованием обычных классов, вы можете наследоваться от нужного вам `View`, переписать нужную вам часть и использовать в работе.

## **CompoundView**

Или, если перевести — **составной `View`**. Собственно, я думаю всё понятно из названия: мы из нескольких уже созданных `View` делаем своеобразный `ViewGroup`, мы можем создать для него класс, чтобы обрабатывать взаимодействие с ним, и внедрять его в другие `layout` как одну единицу `View`.
