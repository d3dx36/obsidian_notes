**Диалоговое окно** — это окно, в котором вам предлагается сделать какой-то выбор или ввести дополнительную информацию.

Как правило, диалоговое окно заполняет только часть экрана и используется как подтверждение действий пользователя, например, о том, хочет ли пользователь покинуть приложение.

![img](https://lms-cdn.skillfactory.ru/assets/courseware/v1/ff83745522102de0bfa6e5c10903ac0f/asset-v1:SkillFactory+ANDROID-NEW+2020+type@asset+block/ANDROID_28.6_2.png)

Источник: [developer.android.com](https://developer.android.com/images/ui/dialogs.png?hl=ru)

За создание диалогового окна отвечает класс `**Dialog**`. Это базовый класс, и создавать диалоговые окна напрямую от это класса не рекомендуется, так как есть уже конкретные его реализации, которые и можно менять. Вместо этого стоит использовать либо `**AlertDialog**` и `**DialogFragment**` для предоставления какого-то выбора пользователю или для ввода какой-то информации, либо `**DatePickerDialog**` для выбора даты или `**TimePickerDialog**` для выбора времени.

## **AlertDialog**

Давайте реализуем `AlertDialog` для того, чтобы пользователь случайно не закрыл приложение кнопкой «назад». Для этого нам надо в нашем активити переопределить метод `onBackPressed()`, этот метод вызывается, когда мы нажимаем на системную кнопку **Back**.

`override fun onBackPressed() {`
   `super.onBackPressed()`
`}`

Теперь давайте создадим наш диалог:

`AlertDialog.Builder(this)`
   `.setTitle("Вы хотите выйти?")`
   `.setIcon(R.drawable.ic_menu_gallery)`
   `.setPositiveButton("Да") { _, _ ->`
       `finish()`
   `}`
   `.setNegativeButton("Нет") { _, _ ->`

   `}`
   `.setNeutralButton("Не знаю") { _, _ ->`
       `Toast.makeText(this, "Решайся", Toast.LENGTH_SHORT).show()`
   `}`
   `.show()`

Вот такой код будет у нашего диалога, а теперь давайте разберём построчно:

|                                                                                                                    |                                                                                                                                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `.setTitle("Вы хотите выйти?")`                                                                                      | Устанавливаем заголовок (помним про ресурсы строк).                                                                                                                                                                            |
| `.setIcon(R.drawable.ic_menu_gallery)`                                                                               | Устанавливаем иконку.                                                                                                                                                                                                          |
| `.setPositiveButton("Да") { _, _ -><br>       finish()<br>}`                                                         | Устанавливаем кнопку положительного ответа и прикрепляем к ней слушателя. Эта кнопка будет располагаться справа.                                                                                                               |
| `.setNegativeButton("Нет") { _, _ -> }`                                                                              | Устанавливаем кнопку отрицательного ответа, в данном случае мы хотим, чтобы диалог просто закрылся, поэтому никакой логики внутри нет, хотя она может быть. Эта кнопка будет располагаться справа, после положительной кнопки. |
| `.setNeutralButton("Не знаю") { _, _ -><br>       Toast.makeText(this, "Решайся", Toast.LENGTH_SHORT).show()<br>  }` | Также можно добавить еще одну кнопку, если вам двух мало. Она будет располагаться слева.                                                                                                                                       |
| `.show()`                                                                                                            | И после того как мы всё сформировали, можно показать диалог.                                                                                                                                                                   |

## **DialogFragment**

Этот диалог у нас даже больше не диалог, а фрагмент, который очень хочет быть диалогом. Создаваться он может и как диалог, то есть с помощью _Builder_, и в коде. Второй способ интереснее, потому что мы можем сделать полностью свою вёрстку, давайте этот вариант и рассмотрим.

Для начала нам нужна вёрстка, особо выдумывать не будем, просто заголовок и три кнопки:

`<?xml version="1.0" encoding="utf-8"?>`
`<LinearLayout`
   `xmlns:android="http://schemas.android.com/apk/res/android"`
   `android:layout_width="wrap_content"`
   `android:layout_height="match_parent"`
   `android:orientation="vertical">`
   `<TextView`
       `android:id="@+id/text_header"`
       `android:layout_width="wrap_content"`
       `android:layout_height="wrap_content"`
       `android:layout_gravity="center"`
       `android:layout_margin="20dp"`
       `android:textColor="@android:color/black"`
       `android:textSize="25sp"`
       `android:text="Быть или не быть?">`
   `</TextView>`
   `<LinearLayout`
       `android:layout_width="wrap_content"`
       `android:layout_height="wrap_content">`
       `<Button`
           `android:id="@+id/btn_y"`
           `android:layout_width="wrap_content"`
           `android:layout_height="wrap_content"`
           `android:text="Быть">`
       `</Button>`
       `<Button`
           `android:id="@+id/btn_n"`
           `android:layout_width="wrap_content"`
           `android:layout_height="wrap_content"`
           `android:text="Не быть">`
       `</Button>`
       `<Button`
           `android:id="@+id/btn_other"`
           `android:layout_width="wrap_content"`
           `android:layout_height="wrap_content"`
           `android:text="Эээ...">`
       `</Button>`
   `</LinearLayout>`
`</LinearLayout>`

Отлично, разметка готова, теперь сделаем для неё класс, в котором мы будем все это обрабатывать. Чтобы все работало, нужно наследоваться от `DialogFragment()`:

`class DialogFragment1 : DialogFragment() {`
   `override fun onCreateView(`
       `inflater: LayoutInflater, container: ViewGroup?,`
       `savedInstanceState: Bundle?`
   `): View? {`
       `return inflater.inflate(R.layout.dialog_fragment, container, false)`

   `}`

   `override fun onViewCreated(view: View, savedInstanceState: Bundle?) {`
       `super.onViewCreated(view, savedInstanceState)`

       //Привязываем кнопки
       btn_y.setOnClickListener {
           Toast.makeText(view.context, "Yes", Toast.LENGTH_SHORT).show()
       }
       btn_n.setOnClickListener {
           Toast.makeText(view.context, "No", Toast.LENGTH_SHORT).show()
       }
       btn_other.setOnClickListener{
           Toast.makeText(view.context, "Other", Toast.LENGTH_SHORT).show()
       }
   }
   //Этот выполняется, когда диалог закрывается
   `override fun onDismiss(dialog: DialogInterface) {`
       `super.onDismiss(dialog)`
   `}`

   //Этот метод срабатывает когда мы отменяем диалог кнопкой назад или нажатием вне области
   `override fun onCancel(dialog: DialogInterface) {`
       `super.onCancel(dialog)`
   `}`
`}`

Теперь мы можем по нажатию кнопки «Назад» создать наш `DialogFragment`. Обратите внимание, что нам понадобится `FragmentManager`:

`override fun onBackPressed() {`
   `DialogFragment1().show(supportFragmentManager, "dialog1")`
`}`

`package com.example.test`  
  
`import android.app.AlertDialog`  
`import android.os.Bundle`  
`import android.widget.Toast`  
`import androidx.activity.ComponentActivity`  
`import androidx.activity.OnBackPressedCallback`  
`import androidx.activity.compose.setContent`  
`import androidx.activity.enableEdgeToEdge`  
`import androidx.compose.foundation.layout.fillMaxSize`  
`import androidx.compose.foundation.layout.padding`  
`import androidx.compose.material3.Scaffold`  
`import androidx.compose.material3.Text`  
`import androidx.compose.runtime.Composable`  
`import androidx.compose.ui.Modifier`  
`import androidx.compose.ui.tooling.preview.Preview`  
`import com.example.test.ui.theme.TestTheme`  
  
`class MainActivity : ComponentActivity() {`  
    `override fun onCreate(savedInstanceState: Bundle?) {`  
        `super.onCreate(savedInstanceState)`  
        `val callback = object : OnBackPressedCallback(true) {`  
            `override fun handleOnBackPressed() {`  
                `showExitDialog() // Вызываем наш метод`  
            `}`  
        `}`  
        `onBackPressedDispatcher.addCallback(this, callback)`  
    `}`  
    `private fun showExitDialog() {`  
        `// 1. Создаем конструктор диалога`  
        `val builder = AlertDialog.Builder(this)`  
  
        // 2. Устанавливаем заголовок и текст  
        builder.setTitle("Выход")  
        builder.setMessage("Вы точно хотите выйти из приложения?")  
  
        // 3. Кнопка "Да" (Positive)  
        builder.setPositiveButton("Да") { _, _ ->  
            finish() // Закрывает Activity  
        }  
  
        // 4. Кнопка "Нет" (Negative)  
        builder.setNegativeButton("Нет") { dialog, _ ->  
            dialog.dismiss() // Просто закрывает окно диалога  
        }  
  
        // 5. Показываем диалог  
        builder.show()  
    }  
`}`
