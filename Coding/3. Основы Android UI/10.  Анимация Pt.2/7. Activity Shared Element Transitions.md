## Анимация с общим элементом (Shared Element Transition)

Этот вид анимации используется, когда один и тот же визуальный элемент (например, аватарка или картинка товара) присутствует на обоих экранах, и нужно плавно переместить/смасштабировать его из начального положения в конечное.

### 🧠 Как это работает под капотом (`ViewOverlay`)

Анимация общего элемента происходит внутри **`ViewOverlay`** — специального слоя, который находится над всей иерархией View.

- **Зачем это нужно:** Обычные контейнеры (например, `RecyclerView` или `LinearLayout`) жестко ограничивают свои дочерние элементы. Если бы элемент анимировался внутри своего контейнера, он бы просто "обрезался" на границах при попытке вылететь за них.
    
- **Процесс:** Во время перехода элемент временно извлекается из привычной иерархии, добавляется на `ViewOverlay`, перемещается/меняет размер, а в момент завершения анимации удаляется из overlay, так как уже идеально совпадает с положением элемента на конечном экране.
    

## Пошаговый алгоритм настройки (2 шага)

### Шаг 1. Настройка XML-разметки

Для элемента **на обоих экранах** нужно задать уникальный идентификатор `id` и одинаковое значение для атрибута `android:transitionName`.

XML

```
<!-- activity_main.xml (Начальный экран) -->
<ImageView
   android:id="@+id/image"
   android:layout_width="120dp"
   android:layout_height="120dp"
   android:src="@drawable/android"
   android:transitionName="image_name" />

<!-- activity_second.xml (Конечный экран) -->
<ImageView
   android:id="@+id/image"
   android:layout_width="120dp"
   android:layout_height="120dp"
   android:src="@drawable/android"
   android:transitionName="image_name" />
```

### Шаг 2. Передача пары (Pair) в ActivityOptions

При запуске новой Activity в метод `makeSceneTransitionAnimation` нужно передать сам объект `View` и его `transitionName` в виде пары (`android.util.Pair`).

Kotlin

```
// MainActivity.kt
class MainActivity : Activity() {

   override fun onCreate(savedInstanceState: Bundle?) {
       window.requestFeature(Window.FEATURE_ACTIVITY_TRANSITIONS)
       super.onCreate(savedInstanceState)
       setContentView(R.layout.activity_main)
       
       // Стандартная настройка анимации ухода самого экрана
       window.exitTransition = Slide(Gravity.START).apply {
           duration = 1000
           mode = Slide.MODE_OUT
           excludeTarget(android.R.id.statusBarBackground, true)
           excludeTarget(android.R.id.navigationBarBackground, true)
       }
       
       window.reenterTransition = Slide(Gravity.START).apply {
           excludeTarget(android.R.id.statusBarBackground, true)
           excludeTarget(android.R.id.navigationBarBackground, true)
       }
       
       root.setOnClickListener {
           // Создаем опции перехода, передавая пару (Элемент -> Имя транзишена)
           val activityOptions = ActivityOptions.makeSceneTransitionAnimation(
               this, 
               Pair(image, "image_name") // Указываем общий элемент
           )
           
           startActivity(Intent(this, SecondActivity::class.java), activityOptions.toBundle())
       }
   }
}
```

> [!info] Какая анимация применяется по умолчанию? Если вы явно не указываете тип анимации для общего элемента (через `window.sharedElementEnterTransition`), `TransitionFramework` автоматически использует **`AutoTransition`**. Он плавно перемещает элемент, изменяет его размер и прозрачность (Fade + ChangeBounds).
