## Способы создания переходов (Transitions)

Анимацию перехода между Activity можно настроить двумя способами:

1. **Через XML-атрибуты темы** (глобально).
    
2. **Программно через код** (динамически с гибкой настройкой).
    

### Вариант 1. Настройка через XML

Включается в файле `styles.xml` (или `themes.xml`) для нужной темы:

XML

```
<style name="BaseAppTheme" parent="android:Theme.Material">
   <!-- Включаем переходы для содержимого окна -->
   <item name="android:windowActivityTransitions">true</item>
   
   <!-- Указываем файлы анимации для входа и выхода -->
   <item name="android:windowEnterTransition">@transition/explode</item>
   <item name="android:windowExitTransition">@transition/explode</item>
</style>
```

Пример описания самой анимации в `res/transition/explode.xml`:

XML

```
<?xml version="1.0" encoding="utf-8"?>
<explode xmlns:android="http://schemas.android.com/apk/res/android"
   android:duration="400" />
```

## Пример 1. Прямой и обратный переход (Программно)

Для корректной работы кастомного перехода (например, по свайпу или кнопке «Назад») необходимо настроить обе Activity: и ту, с которой уходим, и ту, на которую открывается переход.

> [!danger] Важное правило Метод `window.requestFeature(Window.FEATURE_ACTIVITY_TRANSITIONS)` **обязательно** должен вызываться в `onCreate` **до** вызова `super.onCreate(savedInstanceState)` и `setContentView(...)`.

### Код MainActivity (Исходная точка)

Kotlin

```
class MainActivity : Activity() {

   override fun onCreate(savedInstanceState: Bundle?) {
       // 1. Включаем поддержку переходов до создания Activity
       window.requestFeature(Window.FEATURE_ACTIVITY_TRANSITIONS)
       super.onCreate(savedInstanceState)
       setContentView(R.layout.activity_main)
       
       // 2. Анимация ВЫХОДА из MainActivity (Slide влево)
       window.exitTransition = Slide(Gravity.START).apply {
           mode = Slide.MODE_OUT
           // Исключаем системные бары, чтобы они не дёргались при анимации
           excludeTarget(android.R.id.statusBarBackground, true)
           excludeTarget(android.R.id.navigationBarBackground, true)
       }
       
       // 3. Анимация ПОВТОРНОГО ВХОДА при возврате назад (Reenter)
       window.reenterTransition = Slide(Gravity.START).apply {
           duration = 1000
           excludeTarget(android.R.id.statusBarBackground, true)
           excludeTarget(android.R.id.navigationBarBackground, true)
       }
       
       root.setOnClickListener {
           // 4. Передаем опции анимации в startActivity
           val activityOptions = ActivityOptions.makeSceneTransitionAnimation(this)
           startActivity(Intent(this, SecondActivity::class.java), activityOptions.toBundle())
       }
   }
}
```

### Код SecondActivity (Целевая точка)

Kotlin

```
class SecondActivity : Activity() {

   override fun onCreate(savedInstanceState: Bundle?) {
       window.requestFeature(Window.FEATURE_ACTIVITY_TRANSITIONS)
       
       // Разрешаем перекрывать анимации (не ждать полного окончания exitTransition)
       window.allowEnterTransitionOverlap = true
       window.allowReturnTransitionOverlap = true
       
       super.onCreate(savedInstanceState)
       setContentView(R.layout.activity_second)
       
       // Анимация ВХОДА на SecondActivity (Slide справа)
       window.enterTransition = Slide(Gravity.END).apply {
           duration = 1000
           excludeTarget(android.R.id.statusBarBackground, true)
           excludeTarget(android.R.id.navigationBarBackground, true)
       }
       
       // Анимация ОБРАТНОГО ВЫХОДА при нажатии Назад (Return)
       window.returnTransition = Slide(Gravity.END).apply {
           mode = Slide.MODE_OUT
           excludeTarget(android.R.id.statusBarBackground, true)
           excludeTarget(android.R.id.navigationBarBackground, true)
       }
   }
}
```

> [!info] Нюанс работы Reenter и Return Если не задать `returnTransition` и `reenterTransition`, обратный переход отработает некорректно (анимация возврата для `MainActivity` не выполнится, так как по умолчанию она ищет `enterTransition`, который для неё не задан).

## Пример 2. Анимация содержимого внутри Activity

Можно синхронизировать появление конкретных View-элементов на экране (например, `ImageView`) с общим переходом Activity с помощью `TransitionManager.beginDelayedTransition`.

### Сценарий

На `SecondActivity` есть изначально скрытый элемент (`android:visibility="invisible"`). Мы хотим, чтобы при старте перехода экрана этот элемент плавно выехал снизу.

### Реализация в SecondActivity

Kotlin

```
window.enterTransition = Fade().apply {
    duration = 1000
    excludeTarget(android.R.id.statusBarBackground, true)
    excludeTarget(android.R.id.navigationBarBackground, true)
    
    // Вешаем слушатель на старт анимации Activity
    addListener(onStart = {
        val slide = Slide() // По умолчанию Gravity.BOTTOM (выезжает снизу)
        
        image.visibility = View.INVISIBLE
        // Запускаем отложенную анимацию изменений внутри root-контейнера
        TransitionManager.beginDelayedTransition(root, slide)
        // Меняем состояние, это изменение автоматически анимируется с помощью slide
        image.visibility = View.VISIBLE
    })
}
```
