# Android Transitions Framework

В библиотеке анимаций переходов основными являются три класса:
1. `Scene` (Сцена) — описывает состояние интерфейса.
2. `Transition` (Переход) — задает характер анимации.
3. `TransitionManager` (Менеджер переходов) — управляет сменой сцен.

### Основные возможности Framework:
*   **Group-level animations:** Анимация целых иерархий `View`. Достаточно указать корневой `ViewGroup`, и анимация автоматически применится ко всем дочерним элементам.
*   **Transition-based animation:** Анимации, полностью завязанные на переходах между состояниями.
*   **Built-in animations:** Встроенные автоматические анимации (растворение, затемнение, изменение размера, движение и т.д.).
*   **Resource file support:** Поддержка описания анимаций в XML-файлах ресурсов, что позволяет не перегружать Kotlin-код.
*   **Lifecycle callbacks:** Набор методов для полного контроля за жизненным циклом и воспроизведением анимации.

## 🖼 Класс Scene (Сцена)

**Сцена** — это класс-обертка над контейнером `ViewGroup`. Она описывает конкретное состояние этого контейнера и всех объектов внутри него. Анимация — это просто процесс перехода от одной сцены к другой.

> [!warning] Важное правило
> Объект `View` может находиться **только в одном** контейнере единовременно.
> Внутри `sceneRoot` (корневой сцены) в каждый момент времени может содержаться **только одна** активная сцена.

Сигнатура основного конструктора:
```kotlin
Scene(sceneRoot: ViewGroup?, layout: View?)

```

### Способ 1: Программное создание сцен

Используется, когда состояния переключаются в пределах одной разметки.

📁 **activity_main.xml**

XML

```
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout 
    xmlns:android="[http://schemas.android.com/apk/res/android](http://schemas.android.com/apk/res/android)"
    xmlns:app="[http://schemas.android.com/apk/res-auto](http://schemas.android.com/apk/res-auto)"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <FrameLayout android:id="@+id/scene_root" android:layout_height="200dp" android:layout_width="200dp" app:layout_constraintBottom_toBottomOf="parent" app:layout_constraintEnd_toEndOf="parent" app:layout_constraintStart_toStartOf="parent" app:layout_constraintTop_toTopOf="parent">

        <TextView android:id="@+id/text1" android:layout_height="wrap_content" android:layout_width="wrap_content" android:text="Text1"/>
        <TextView android:id="@+id/text2" android:layout_height="wrap_content" android:layout_width="wrap_content" android:text="Text2"/>
    </FrameLayout>
</androidx.constraintlayout.widget.ConstraintLayout>
```

📁 **MainActivity.kt**

Kotlin

```
class MainActivity : AppCompatActivity() {
   override fun onCreate(savedInstanceState: Bundle?) {
       super.onCreate(savedInstanceState)
       setContentView(R.layout.activity_main)
       
       // Создаем две сцены, привязанные к одному scene_root
       val scene1 = Scene(scene_root, text1)
       val scene2 = Scene(scene_root, text2)
   }
}
```

### Способ 2: Определение сцен через Layout-ресурсы

Используется, когда для каждого состояния создается отдельный XML-файл.

Для создания используется статический метод `Scene.getSceneForLayout(sceneRoot, layoutId, context)`.

📁 **MainActivity.kt**

Kotlin

```
val scene1 = Scene.getSceneForLayout(scene_root, R.layout.scene1, this)
val scene2 = Scene.getSceneForLayout(scene_root, R.layout.scene2, this)

// Прямой запуск сцены без менеджера:
scene1.enter() 
```

> [!tip] События сцены На событие входа в сцену можно повесить коллбек: `scene1.setEnterAction { /* твой код */ }`. Для выхода используется метод `exit()`.

## 🔀 Transition Manager

`TransitionManager` аккумулирует в себе все сцены и правила переходов между ними, избавляя от ручного написания анимаций.

### Способ 1: Программный (по умолчанию)

Если при переходе не задавать конкретный `Transition`, система применит стандартный, автоматически определив изменившиеся свойства элементов.

Kotlin

```
val transitionManager = TransitionManager()
transitionManager.transitionTo(scene1)

// Для установки конкретных правил используется:
// transitionManager.setTransition(fromScene, toScene, transition)
```

> [!success] Быстрый переход (Без создания менеджера) Можно выполнить переход в один в один клик с помощью статического метода: `TransitionManager.go(scene1)`

### Способ 2: Определение через XML-ресурсы

#### Шаг 1. Описание самого перехода (Transition)

Создается в папке `res/transition/`.

📁 **res/transition/t1.xml**

XML

```
<?xml version="1.0" encoding="utf-8"?>
<transitionSet xmlns:android="[http://schemas.android.com/apk/res/android](http://schemas.android.com/apk/res/android)"
   android:transitionOrdering="sequential"> <!-- Порядок: together (вместе) | sequential (последовательно) -->
   
   <fade android:fadingMode="fade_out" android:duration="400"/>
   <changeBounds />
   <fade android:fadingMode="fade_in" android:duration="400"/>
</transitionSet>
```

> [!info] Шпаргалка по XML-атрибутам переходов
> 
> - `transitionOrdering` — порядок (`together` — параллельно, `sequential` — по очереди).
>     
> - `duration` — длительность в мс.
>     
> - `fadingMode` — режим затухания (`fade_in`, `fade_out`, `fade_in_out`).
>     
> - `<targets>` — позволяет через теги `<target>` или `<exclude>` точечно применять/исключать анимацию для конкретных `id`, `Class` или `Name`.
>     

#### Шаг 2. Описание Менеджера (TransitionManager)

Связывает сцены и анимации вместе.

📁 **res/transition/transition_manager.xml**

XML

```
<?xml version="1.0" encoding="utf-8"?>
<transitionManager xmlns:android="[http://schemas.android.com/apk/res/android](http://schemas.android.com/apk/res/android)">
   <transition
       android:fromScene="@layout/scene1"
       android:toScene="@layout/scene2"
       android:transition="@transition/t1" />
   <transition
       android:fromScene="@layout/scene2"
       android:toScene="@layout/scene1"
       android:transition="@transition/t1" />
</transitionManager>
```

#### Шаг 3. Инфлейт менеджера в коде

Kotlin

```
val transitionManager = TransitionInflater.from(this)
    .inflateTransitionManager(R.transition.transition_manager, scene_root)
```

## 🛠 Практический пример: Анимация кнопки

Задача: Кнопка на первой сцене находится по центру. На второй сцене она увеличивается, перемещается вниз и меняет дизайн.

> [!critical] Главное условие авто-анимации Чтобы фреймворк понял, что объект на Сцене 1 и Сцене 2 — это **один и тот же элемент**, у него на обоих layout-файлах должен быть абсолютно **одинаковый `android:id`** (в данном случае `android:id="@+id/button"`).

📁 **scene1.xml (Исходное состояние)**

XML

```
<?xml version="1.0" encoding="utf-8"?>
<RelativeLayout android:id="@+id/scene" android:layout_height="match_parent" android:layout_width="match_parent" xmlns:android="[http://schemas.android.com/apk/res/android](http://schemas.android.com/apk/res/android)">
   <Button android:id="@+id/button" android:layout_centerInParent="true" android:layout_height="50dp" android:layout_width="200dp" android:text="button"/>
</RelativeLayout>
```

📁 **scene2.xml (Конечное состояние)**

XML

```
<?xml version="1.0" encoding="utf-8"?>
<RelativeLayout android:id="@+id/scene" android:layout_height="match_parent" android:layout_width="match_parent" xmlns:android="[http://schemas.android.com/apk/res/android](http://schemas.android.com/apk/res/android)">
   <Button android:background="@color/colorAccent" android:id="@+id/button" android:layout_alignParentBottom="true" android:layout_centerHorizontal="true" android:layout_height="50dp" android:layout_marginBottom="50dp" android:layout_width="200dp" android:scaleX="1.3" android:scaleY="1.3" android:text="button"/>
</RelativeLayout>
```

📁 **MainActivity.kt (Логика переключения по нажатию)**

Kotlin

```
class MainActivity : AppCompatActivity() {

   override fun onCreate(savedInstanceState: Bundle?) {
       super.onCreate(savedInstanceState)
       setContentView(R.layout.activity_main)
       
       val scene1 = Scene.getSceneForLayout(scene_root, R.layout.scene1, this)
       val scene2 = Scene.getSceneForLayout(scene_root, R.layout.scene2, this)
       
       // Загружаем менеджер из XML (использует анимацию changeBounds)
       val transitionManager = TransitionInflater.from(this)
           .inflateTransitionManager(R.transition.t_manager, scene_root)
       
       // Устанавливаем стартовую сцену
       transitionManager.transitionTo(scene1)
       
       // По клику на кнопку переносим пользователя на сцену 2
       button.setOnClickListener {
           transitionManager.transitionTo(scene2)
       }
   }
}
```
