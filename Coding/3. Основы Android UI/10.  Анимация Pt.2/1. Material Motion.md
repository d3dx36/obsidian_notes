# Material Motion System

**Material Motion System** — это система материальных анимаций в Material Design, представляющая собой набор шаблонов переходов между экранами или состояниями элементов. 

**Главная цель:** помочь пользователю понять контекст происходящего в приложении и упростить навигацию.

---
## 🧩 4 основных паттерна анимации

### 1. Преобразования контейнеров (Container transform)
Используется для элементов, находящихся внутри контейнеров. Анимируется сам контейнер, чтобы показать пользователю, *откуда* появился новый объект на экране.

*   **Применение:**
    *   Карточка из списка при клике плавно растягивается на весь экран (с небольшим увеличением по оси Z).
    *   Элемент списка преобразуется в страницу деталей.
    *   FAB (Floating Action Button) разворачивается в панель создания заметки/напоминания.
    *   Поле поиска расширяется в экран поиска.
*   📌 *Примечание:* Не обязательно растягивать элемент на весь экран, трансформация может быть частичной.

### 2. Анимации общей оси (Shared axis)
Применяется, когда элементы логически связаны и двигаются по одной из трех координатных осей.

> [!info] Системы координат в Android
> Начало координат $(0,0)$ находится в **левом верхнем углу** экрана. 
> *   **X** — горизонталь (влево / вправо).
> *   **Y** — вертикаль (вверх / **вниз — положительное значение**).
> *   **Z** — глубина (от пользователя / к пользователю).

*   **Примеры движения:**
    *   **По оси X:** Экраны шагов регистрации (вперед/назад).
    *   **По оси Y:** Вертикальное переключение вкладок. Один элемент «уезжает» вверх, второй «выезжает» снизу.
    *   **По оси Z:** Поверхности будто проходят сквозь друг друга (эффект приближения/отдаления).

### 3. Переход выцветанием (Fade through)
Используется для **не связанных между собой элементов**, которые выполняют разные функции.

*   **Применение:**
    *   Переключение между независимыми экранами в нижнем меню навигации (Bottom Navigation).
    *   Обновление данных на текущем экране.
    *   Смена аккаунта в профиле.
*   ⚙️ **Механика по спецификации:** 
    1. Первый контейнер полностью исчезает (Fade out) и отдаляется по оси Z.
    2. Новый контейнер появляется из прозрачности (Fade in) и идет «на нас».
    3. *Правило масштабирования:* Чтобы создать красивый эффект приближения/отдаления, масштабирование нового объекта начинается не с 0%, а с **92%** от его финального размера.

### 4. Анимации появления и исчезновения (Fade)
Используется для элементов, которые временно появляются поверх основного контента, а затем исчезают.

*   **Стадии:**
    *   **Fade in (появление):** Объект становится видимым и плавно увеличивается от **80% до 100%**.
    *   **Fade out (исчезновение):** Объект просто плавно теряет непрозрачность до 0%.
*   **Применение:**
    *   Диалоговые окна (например, выбор даты/календарь).
    *   Выпадающие списки и меню.
    *   Всплывающие уведомления (Snackbar).
    *   Появление/скрытие кнопки FAB.

## 🍏 Анимации, основанные на физике
Делают интерфейс «живым» и реалистичным за счет симуляции законов природы.

### Fling (Взмах / Импульс)
Анимация списков и прокрутки, основанная на понятии **импульса** и **трения**.
*   **Как работает:** Скорость максимальна в момент жеста пользователя, затем постепенно гасится силой трения, пока не упадет до нуля.
*   *Особенность:* Чем сильнее и резче жест пользователя, тем больше начальный импульс и дольше крутится список.

### Spring (Пружина)
Анимация, завязанная на поведении физической пружины.
*   **Как работает:** Объект виртуально привязан к пружине. Чем дальше пользователь оттягивает элемент от его стандартного положения («точки покоя»), тем сильнее сила упругости тянет его обратно, создавая характерный «отскок».
