## 1. EditText

`EditText` — это текстовое поле, которое умеет принимать ввод с клавиатуры.

### Основной атрибут: `android:inputType`

Этот атрибут определяет, какую клавиатуру увидит пользователь и как будет вести себя текст.

|**Значение**|**Описание**|**Особенности**|
|---|---|---|
|`"text"`|Обычный текст|Стандартная клавиатура.|
|`"textEmailAddress"`|Электронная почта|Появляется символ `@`.|
|`"number"`|Целые числа|Только цифры (без минуса и точки).|
|`"numberDecimal"`|Дробные числа|Позволяет ставить точку/запятую.|
|`"numberSigned"`|Отрицательные числа|Позволяет ставить знак `-`.|
|`"textPassword"`|Пароль|Скрывает символы точками.|
|`"textMultiLine"`|Многострочный ввод|Позволяет переносить текст на новую строку.|
|`"textCapWords"`|Заглавные буквы|Каждое слово начинается с большой буквы.|

> [!TIP]
> 
> Атрибуты можно комбинировать через вертикальную черту:
> 
> `android:inputType="numberDecimal|numberSigned"` — для ввода отрицательных дробных чисел.

### Атрибуты оформления (Hint и кастомизация)

- `android:hint="Текст"` — подсказка, которая исчезает при начале ввода.
    
- `android:textColorHint` — меняет цвет текста подсказки.
    
- `android:textColorHighlight` — меняет цвет фона при выделении текста.

## 2. TextInputLayout (Material Design)

Это контейнер из библиотеки **Google Material Components**, который оборачивает `TextInputEditText` и добавляет современную анимацию и функционал.

### Пример базовой разметки

XML

```
<com.google.android.material.textfield.TextInputLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:hint="Введите имя">

    <com.google.android.material.textfield.TextInputEditText
        android:layout_width="match_parent"
        android:layout_height="wrap_content" />

</com.google.android.material.textfield.TextInputLayout>
```

### Стили оформления

Чтобы стили работали, тема приложения должна быть унаследована от `Theme.MaterialComponents`.

1. **OutlinedBox** (Рамка вокруг поля):
    
    `style="@style/Widget.MaterialComponents.TextInputLayout.OutlinedBox"`
    
2. **FilledBox** (Залитый фон, по умолчанию):
    
    `style="@style/Widget.MaterialComponents.TextInputLayout.FilledBox"`
    

### Счетчик символов (Character Counter)

Можно ограничить ввод и показывать пользователю остаток символов прямо в `TextInputLayout`:

- `app:counterEnabled="true"` — включает счетчик.
    
- `app:counterMaxLength="100"` — задает максимальный лимит.
    

XML

```
<com.google.android.material.textfield.TextInputLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    app:counterEnabled="true"
    app:counterMaxLength="20">
    </com.google.android.material.textfield.TextInputLayout>
```

---

### Итог

- Используй **`inputType`**, чтобы упростить жизнь пользователю (вызывай нужную клавиатуру сразу).
    
- Используй **`TextInputLayout`**, если хочешь соответствовать гайдлайнам Material Design и получить красивые анимации "из коробки".
