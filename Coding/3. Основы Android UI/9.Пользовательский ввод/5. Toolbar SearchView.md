# 🔍 Реализация поиска через SearchView (Android)

**Теги:** #Android #Kotlin #ViewBinding #UI #SearchView #Tutorial

---

## 📋 Обзор задачи

Создание интерфейса поиска в верхней панели приложения (Toolbar). При вводе текста и нажатии кнопки "Поиск", приложение проверяет наличие элемента в списке и выводит результат на экран, меняя цвет текста.

---

## 🛠 Настройка проекта

### 1. Включение View Binding

В файле `build.gradle.kts` (Module: app):

Kotlin

```
android {
    viewBinding.enable = true
}
```

### 2. Ресурс меню (`res/menu/search_menu.xml`)

Создаем элемент поиска. Ключевой атрибут здесь — `app:actionViewClass`.

XML

```
<?xml version="1.0" encoding="utf-8"?>
<menu xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto">
    <item
        android:id="@+id/search"
        android:title="Поиск"
        android:icon="@android:drawable/ic_menu_search"
        app:showAsAction="always|collapseActionView"
        app:actionViewClass="androidx.appcompat.widget.SearchView" />
</menu>
```

> [!important] Важно
> 
> Используйте `androidx.appcompat.widget.SearchView`, чтобы обеспечить совместимость со старыми версиями Android.

Простая разметка с `TextView` для отображения статуса поиска.

## 🧠 Логика (MainActivity.kt)

### Основные моменты реализации:

1. **View Binding**: Инициализация через `inflate(layoutInflater)`.
    
2. **onCreateOptionsMenu**: "Раздувание" меню и поиск `menuItem`.
    
3. **OnQueryTextListener**: Слушатель, который реагирует на ввод.
    

Kotlin

```
class MainActivity : AppCompatActivity() {

    private lateinit var binding: ActivityMainBinding
    private val list = mutableListOf<String>()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityMainBinding.inflate(layoutInflater)
        setContentView(binding.root)

        // Имитация базы данных
        repeat(10) { i -> list.add("item$i") }
    }

    override fun onCreateOptionsMenu(menu: Menu): Boolean {
        menuInflater.inflate(R.menu.search_menu, menu)

        val searchItem = menu.findItem(R.id.search)
        val searchView = searchItem.actionView as SearchView

        searchView.setOnQueryTextListener(object : SearchView.OnQueryTextListener {
            // Нажатие на кнопку поиска на клавиатуре
            override fun onQueryTextSubmit(query: String?): Boolean {
                checkItemInList(query)
                return true 
            }

            // Изменение текста в реальном времени
            override fun onQueryTextChange(newText: String?): Boolean {
                return false
            }
        })

        return super.onCreateOptionsMenu(menu)
    }

    private fun checkItemInList(query: String?) {
        if (list.contains(query)) {
            binding.resultText.text = "Найдено: $query"
            binding.resultText.setTextColor(ContextCompat.getColor(this, android.R.color.holo_green_dark))
        } else {
            binding.resultText.text = "Не найдено"
            binding.resultText.setTextColor(ContextCompat.getColor(this, android.R.color.holo_red_dark))
        }
    }
}
```

## ⚠️ Возможные ошибки

> [!danger] Ошибка темы (IllegalStateException)
> 
> Если приложение падает с ошибкой `You need to use a Theme.AppCompat theme`, проверьте файл `AndroidManifest.xml`.
> 
> **Решение:** Убедитесь, что тема в `parent` использует AppCompat, например:
> 
> `parent="Theme.AppCompat.DayNight.DarkActionBar"`

## 💡 Идеи для улучшения

- [ ] **Поиск без учета регистра**: использовать `list.any { it.equals(query, ignoreCase = true) }`.
    
- [ ] **Живой поиск**: перенести вызов `checkItemInList` в метод `onQueryTextChange`.
    
- [ ] **RecyclerView**: вместо одного `TextView` фильтровать целый список данных.
