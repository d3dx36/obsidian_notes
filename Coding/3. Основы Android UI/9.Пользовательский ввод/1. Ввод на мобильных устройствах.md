# Создание кастомной клавиатуры через InputMethodService

> [!WARNING] Дисклеймер `KeyboardView` и сопутствующие классы помечены как **Deprecated**. Однако это лучший способ быстро изучить механику работы soft-клавиатур в Android изнутри.

---

## 1. Главный Layout клавиатуры

Создаем файл `res/layout/custom_keyboard.xml`. Это контейнер, в котором будет отображаться наша клавиатура.

XML

```
<?xml version="1.0" encoding="utf-8"?>
<android.inputmethodservice.KeyboardView 
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/custom_keyboard"
    android:layout_width="match_parent" 
    android:layout_height="match_parent"
    android:keyPreviewLayout="@layout/keyboard_preview"
    android:background="@android:color/holo_orange_dark"
    android:layout_alignParentBottom="true" />
```

**Особенности атрибутов:**

- `android:layout_alignParentBottom="true"` — прижимает клавиатуру к нижнему краю.
    
- `android:keyPreviewLayout` — ссылка на макет «всплывающего» окна, которое появляется при нажатии на клавишу.
    

---

## 2. Верстка Preview клавиши

Создаем `res/layout/keyboard_preview.xml`. Здесь настраивается внешний вид подсказки над кнопкой.

XML

```
<?xml version="1.0" encoding="utf-8"?>
<TextView xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:gravity="center"
    android:background="@android:color/white"
    android:textColor="@android:color/black"
    android:textSize="30sp" />
```

## 3. Описание сетки клавиш (XML Resources)

Для начала создадим директорию: `res` → `New` → `Android Resource Directory` → **Resource Type: xml**.

### Файл `res/xml/num_pad.xml`

Здесь описывается структура кнопок (ряды и символы).

XML

```
<?xml version="1.0" encoding="utf-8"?>
<Keyboard xmlns:android="http://schemas.android.com/apk/res/android"
    android:keyWidth="30%p"
    android:keyHeight="30dp"
    android:horizontalGap="6%p"
    android:verticalGap="5%p">

    <Row>
        <Key android:codes="1" android:keyLabel="1" android:keyEdgeFlags="left"/>
        <Key android:codes="2" android:keyLabel="2" />
        <Key android:codes="3" android:keyLabel="3" android:keyEdgeFlags="right"/>
    </Row>

    <Row>
        <Key android:codes="4" android:keyLabel="4" android:keyEdgeFlags="left"/>
        <Key android:codes="5" android:keyLabel="5" />
        <Key android:codes="6" android:keyLabel="6" android:keyEdgeFlags="right"/>
    </Row>

    <Row>
        <Key android:codes="7" android:keyLabel="7" android:keyEdgeFlags="left"/>
        <Key android:codes="8" android:keyLabel="8" />
        <Key android:codes="9" android:keyLabel="9" android:keyEdgeFlags="right"/>
    </Row>
</Keyboard>
```

> [!TIP] `%p` — это проценты относительно родительского контейнера.

### Файл `res/xml/method.xml`

Указывает системе на тип метода ввода.

XML

```
<?xml version="1.0" encoding="utf-8"?>
<input-method xmlns:android="http://schemas.android.com/apk/res/android">
    <subtype android:imeSubtypeMode="keyboard"/>
</input-method>
```

## 4. Реализация сервиса (Kotlin)

Создаем класс `InputMethodServiceImpl.kt`, который связывает логику и верстку.

Kotlin

```
import android.inputmethodservice.InputMethodService
import android.inputmethodservice.Keyboard
import android.inputmethodservice.KeyboardView
import android.view.View

@Suppress("DEPRECATION")
class InputMethodServiceImpl : InputMethodService(), KeyboardView.OnKeyboardActionListener {

    // Привязываем верстку клавиатуры
    override fun onCreateInputView(): View {
        val keyboardView = layoutInflater.inflate(R.layout.custom_keyboard, null) as KeyboardView
        val keyboard = Keyboard(this, R.xml.num_pad)
        
        keyboardView.keyboard = keyboard
        keyboardView.setOnKeyboardActionListener(this)

        return keyboardView
    }

    // Обработка нажатия на клавишу
    override fun onKey(primaryCode: Int, keyCodes: IntArray?) {
        val ic = currentInputConnection ?: return
        // Отправляем текст в активное поле ввода
        ic.commitText(primaryCode.toString(), 1)
    }

    // Пустые реализации обязательных методов интерфейса
    override fun onPress(p0: Int) {}
    override fun onRelease(p0: Int) {}
    override fun onText(p0: CharSequence?) {}
    override fun swipeLeft() {}
    override fun swipeRight() {}
    override fun swipeDown() {}
    override fun swipeUp() {}
}
```

## 5. Регистрация в AndroidManifest.xml

Сервис клавиатуры должен быть объявлен внутри тега `<application>`.

XML

```
<service 
    android:name=".InputMethodServiceImpl"
    android:permission="android.permission.BIND_INPUT_METHOD"
    android:exported="true">
    <intent-filter>
        <action android:name="android.view.InputMethod"/>
    </intent-filter>

    <meta-data 
        android:name="android.view.im"
        android:resource="@xml/method"/>
</service>
```

---

## Итог

1. **Установите** приложение на устройство.
    
2. Зайдите в **Настройки** → **Язык и ввод** → **Управление экранными клавиатурами**.
    
3. **Включите** вашу новую клавиатуру.
    
4. Теперь в любом `EditText` вы сможете выбрать свою (пусть и немного «яркую») оранжевую клавиатуру!
