Android работа с буфером обмена строится на взаимодействии с **Content Provider** через два ключевых класса:

1. **`ClipboardManager`** — управляет системным сервисом (копирование/вставка).
    
2. **`ClipData`** — контейнер для данных, который содержит описание (`ClipDescription`) и сами элементы (`ClipData.Item`).
    

## 1. Получение ClipboardManager

Объект менеджера не создается вручную, а запрашивается у системы:

Kotlin

```
val clipboardManager = getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
```

## 2. Копирование данных (простой способ)

Для быстрой передачи обычного текста используется статический метод `newPlainText`.

Kotlin

```
// Создаем объект данных: (label, текст)
val clipData = ClipData.newPlainText("user_id", "12345")

// Помещаем данные в системный буфер
clipboardManager.setPrimaryClip(clipData)
```

> [!NOTE] `label` — это техническое описание данных для разработчика, пользователь его не видит. Доступ к нему можно получить через `clipData.description.label`.

---

## 3. Расширенная настройка (MIME-типы и несколько элементов)

Если нужно передать что-то сложнее обычного текста или отправить сразу несколько элементов, используется полная структура.

### MIME-типы данных:

- `MIMETYPE_TEXT_PLAIN` — простой текст.
    
- `MIMETYPE_TEXT_HTML` — текст с HTML-разметкой.
    
- `MIMETYPE_TEXT_URILIST` — ссылки (URI).
    
- `MIMETYPE_TEXT_INTENT` — Intent (например, для ярлыков).
    

### Создание сложного ClipData:

Kotlin

```
// 1. Описываем тип данных
val clipDescription = ClipDescription("MultiData", arrayOf(ClipDescription.MIMETYPE_TEXT_PLAIN))

// 2. Создаем ClipData с первым элементом
val clipData = ClipData(clipDescription, ClipData.Item("Первый элемент"))

// 3. Добавляем дополнительные элементы (в одном ClipData может быть много Item)
clipData.addItem(ClipData.Item("Второй элемент"))

// 4. Отправляем в буфер
clipboardManager.setPrimaryClip(clipData)
```

---

## 4. Извлечение данных из буфера

Чтобы получить данные обратно, нужно обратиться к `primaryClip`.

Kotlin

```
// Проверяем наличие данных и берем первый элемент
val textToPaste = clipboardManager.primaryClip?.getItemAt(0)?.text.toString()

if (textToPaste != "null") {
    binding.textView.text = textToPaste
}
```

> [!WARNING] Важно помнить В системном провайдере одновременно может храниться только **один** объект `ClipData`. Как только любое приложение вызывает `setPrimaryClip`, старые данные заменяются новыми.

### Итог по иерархии:

- **ClipboardManager** (Системный сервис)
    
    - **ClipData** (Контейнер)
        
        - **ClipDescription** (Метаданные: label, MIME-тип)
            
        - **ClipData.Item** (Конкретное значение №1)
            
        - **ClipData.Item** (Конкретное значение №2...)
