```
val myFilter = object : InputFilter {
    override fun filter(
        source: CharSequence?, // 1. ЧТО вставляют
        start: Int,            // 2. Начало вставки в source
        end: Int,              // 3. Конец вставки в source
        dest: Spanned?,        // 4. ЧТО УЖЕ ЕСТЬ в поле
        dstart: Int,           // 5. Где сейчас стоит курсор
        dend: Int              // 6. Конец выделения (если есть)
    ): CharSequence? {         // 7. РЕЗУЛЬТАТ (что в итоге попадет на экран)
        
        // Твоя логика здесь
        return null 
    }
}
```

### Почему так много аргументов?

Android дает тебе полный контроль. Представь, что пользователь не просто печатает букву, а выделяет всё слово и вставляет вместо него текст из буфера обмена.

- **`source`** — это «новичок». Тот текст, который ломится в поле. Если ты вернешь `""` (пустую строку), то новичка не пустят. Если вернешь `null`, то его пустят без изменений.
    
- **`dest`** — это «старичок». Текст, который уже написан. Ты можешь проверить: «Так, если у старичка уже есть точка, то вторую точку из source я не пропущу».
    

---

### Как это использовать проще (Шпаргалка)

Тебе не нужно каждый раз писать все 6 параметров. Чаще всего ты будешь использовать готовые решения или простую проверку символа.

#### 1. Ограничение длины (Самое простое)

Здесь синтаксис максимально дружелюбный:

Kotlin

```
binding.numberInput.filters = arrayOf(InputFilter.LengthFilter(5))
```

**Важно:** `filters` всегда принимает **массив** (`arrayOf`), даже если фильтр всего один. Это потому, что на одно поле можно повесить и лимит длины, и запрет цифр одновременно.

#### 2. Запрет конкретных символов

Допустим, ты не хочешь, чтобы вводили знак «собака» `@`:

Kotlin

```
val noAtFilter = InputFilter { source, _, _, _, _, _ ->
    if (source.contains("@")) "" else null
}
binding.charInput.filters = arrayOf(noAtFilter)
```

Видишь эти **нижние подчеркивания `_`**? В Kotlin это способ сказать: «Тут есть какой-то параметр, но он мне не нужен, я не хочу давать ему имя». Это сильно упрощает чтение.

---

### Итого: как не запутаться?

1. **Запоминай структуру:** `binding.view.filters = arrayOf(...)`.
    
2. **Для простых задач:** используй `InputFilter.LengthFilter` или `InputFilter.AllCaps`.
    
3. **Для своих задач:** используй лямбду `{ source, _, _, _, _, _ -> ... }`. Тебе в 99% случаев будет нужен только `source` (то, что печатают прямо сейчас).
    

Попробуй скопировать этот код:

Kotlin

```
binding.charInput.filters = arrayOf(InputFilter.AllCaps(), InputFilter.LengthFilter(8))
```

Это сделает ввод в твоем текстовом поле капсом и не даст ввести больше 8 букв. Попробуй запустить — если Студия подсветит `InputFilter` красным, просто нажми `Alt+Enter` для импорта.

Стало ли понятнее, зачем там столько запятых и параметров?

## **Input Mask**

В Android-разработке **Input Mask** (маска ввода) — это инструмент, который ограничивает и форматирует текст, вводимый пользователем в реальном времени.

Представь, что пользователю нужно ввести номер телефона. Вместо того чтобы он сам печатал скобки и дефисы, маска делает это за него: он вводит `9111234567`, а в поле отображается `+7 (911) 123-45-67`.

---

### Зачем это нужно?

1. **UX (Пользовательский опыт):** Пользователю не нужно искать спецсимволы на клавиатуре.
    
2. **Валидация:** Маска не дает ввести лишние символы или буквы там, где должны быть цифры.
    
3. **Единообразие данных:** На сервер всегда улетают данные в одном и том же формате.
    

---

### 1. Библиотека input-mask-android больше не существует

> [!danger] Зависимость из старого конспекта не работает
> В конспекте была `com.redmadrobot:input-mask-android:6.1.0`. RedMadRobot закрыли свой Maven-репозиторий, и библиотеки **нет ни в Maven Central, ни в Google Maven** — Gradle просто не найдёт артефакт. Последний релиз вышел в 2021 году.
>
> Хорошая новость: маску ввода можно собрать на чистом `InputFilter` из Android SDK, без единой внешней зависимости. Ниже — рабочий вариант.

### 2. Форматтер: цифры → строка с маской

Сначала напишем функцию, которая превращает набор цифр в отформатированную строку. Разделители расставляются по позиции цифры.

Kotlin

```
object PhoneMask {

    private const val MAX_DIGITS = 10

    fun format(digits: String): String {
        if (digits.isEmpty()) return ""

        val sb = StringBuilder("+7 (")
        digits.forEachIndexed { index, digit ->
            // Разделитель ставим ПЕРЕД цифрой, если до неё дошли
            if (index == 3) sb.append(") ")
            if (index == 6 || index == 8) sb.append('-')
            sb.append(digit)
        }
        return sb.toString()
    }
}
```

Результат по мере ввода:

| Введено | Отображается         |
|---------|----------------------|
| `9`     | `+7 (9`              |
| `911`   | `+7 (911`            |
| `9111`  | `+7 (911) 1`         |
| `911123`| `+7 (911) 123`       |
| `9111234` | `+7 (911) 123-4`   |

### 3. Фильтр, который это применяет

Фильтр должен вернуть **всю** пересобранную строку. Важный нюанс — вставка в середину текста: нельзя просто склеить `dest + source`, нужно вырезать выделенный фрагмент, иначе символы дублируются.

Kotlin

```
class PhoneMaskFilter : InputFilter {
    override fun filter(
        source: CharSequence?,
        start: Int,
        end: Int,
        dest: Spanned?,
        dstart: Int,
        dend: Int
    ): CharSequence? {

        val current = dest.toString()

        // Собираем цифры в правильном порядке: до курсора + вставка + после курсора
        val digits = (
            current.substring(0, dstart) +
            source.toString() +
            current.substring(dend)
        )
            .filter(Char::isDigit)
            .take(MAX_DIGITS)

        return PhoneMask.format(digits)
    }
}
```

Ключевая строка — `.filter(Char::isDigit)`. Она выкидывает всё, что не цифра, поэтому раскладка клавиатуры, вставка из буфера и попытки ввести буквы не ломают маску.

### 4. Подключение к EditText

Kotlin

```
class MainActivity : AppCompatActivity() {

    private lateinit var binding: ActivityMainBinding

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityMainBinding.inflate(layoutInflater)
        setContentView(binding.root)

        binding.editTextPhone.filters = arrayOf(PhoneMaskFilter())

        binding.editTextPhone.addTextChangedListener(object : TextWatcher {
            override fun beforeTextChanged(s: CharSequence?, a: Int, b: Int, c: Int) = Unit
            override fun onTextChanged(s: CharSequence?, a: Int, b: Int, c: Int) = Unit
            override fun afterTextChanged(s: Editable?) {
                // Номер полный, если цифр ровно 10
                val digits = s?.toString()?.filter(Char::isDigit)?.length ?: 0
                binding.btnSend.isEnabled = digits == 10
            }
        })
    }
}
```

> [!warning] Известный нюанс
> Такой фильтр работает на уровне строки, поэтому при вставке в середину текста курсор иногда прыгает в конец. Для большинства полей (номер, дата, карта) это некритично. Если курсор важен — после установки текста возвращай позицию через `Selection.setSelection()`.

### 5. Альтернативы, если нужна готовая библиотека

Если не хочется писать своё, есть поддерживаемые варианты:

- **Material Components** — `com.google.android.material:material:1.14.0` умеет форматировать ввод из коробки для своей `TextInputLayout`, но только под предопределённые сценарии.
- **Своя реализация выше** — ноль зависимостей, полный контроль над форматом. Для учебных и боевых задач оптимально.
