```
val myFilter = object : InputFilter {
    override fun filter(
        source: CharSequence?, // 1. ЧТО вставляют
        start: Int,            // 2. Начало вставки в source
        end: Int,              // 3. Конец вставки в source
        dest: Spanned?,        // 4. ЧТО УЖЕ ЕСТЬ в поле
        dstart: Int,           // 5. Где сейчас стоит курсор
        dend: Int              // 6. Конец выделения (если есть)
    ): CharSequence? {         // 7. РЕЗУЛЬТАТ (что в итоге попадет на экран)
        
        // Твоя логика здесь
        return null 
    }
}
```

### Почему так много аргументов?

Android дает тебе полный контроль. Представь, что пользователь не просто печатает букву, а выделяет всё слово и вставляет вместо него текст из буфера обмена.

- **`source`** — это «новичок». Тот текст, который ломится в поле. Если ты вернешь `""` (пустую строку), то новичка не пустят. Если вернешь `null`, то его пустят без изменений.
    
- **`dest`** — это «старичок». Текст, который уже написан. Ты можешь проверить: «Так, если у старичка уже есть точка, то вторую точку из source я не пропущу».

### Как это использовать проще (Шпаргалка)

Тебе не нужно каждый раз писать все 6 параметров. Чаще всего ты будешь использовать готовые решения или простую проверку символа.

#### 1. Ограничение длины (Самое простое)

Здесь синтаксис максимально дружелюбный:

Kotlin

```
binding.numberInput.filters = arrayOf(InputFilter.LengthFilter(5))
```

**Важно:** `filters` всегда принимает **массив** (`arrayOf`), даже если фильтр всего один. Это потому, что на одно поле можно повесить и лимит длины, и запрет цифр одновременно.

#### 2. Запрет конкретных символов

Допустим, ты не хочешь, чтобы вводили знак «собака» `@`:

Kotlin

```
val noAtFilter = InputFilter { source, _, _, _, _, _ ->
    if (source.contains("@")) "" else null
}
binding.charInput.filters = arrayOf(noAtFilter)
```

Видишь эти **нижние подчеркивания `_`**? В Kotlin это способ сказать: «Тут есть какой-то параметр, но он мне не нужен, я не хочу давать ему имя». Это сильно упрощает чтение.

---

### Итого: как не запутаться?

1. **Запоминай структуру:** `binding.view.filters = arrayOf(...)`.
    
2. **Для простых задач:** используй `InputFilter.LengthFilter` или `InputFilter.AllCaps`.
    
3. **Для своих задач:** используй лямбду `{ source, _, _, _, _, _ -> ... }`. Тебе в 99% случаев будет нужен только `source` (то, что печатают прямо сейчас).
    

Попробуй скопировать этот код:

Kotlin

```
binding.charInput.filters = arrayOf(InputFilter.AllCaps(), InputFilter.LengthFilter(8))
```

Это сделает ввод в твоем текстовом поле капсом и не даст ввести больше 8 букв. Попробуй запустить — если Студия подсветит `InputFilter` красным, просто нажми `Alt+Enter` для импорта.

## **Input Mask**

В Android-разработке **Input Mask** (маска ввода) — это инструмент, который ограничивает и форматирует текст, вводимый пользователем в реальном времени.

Представь, что пользователю нужно ввести номер телефона. Вместо того чтобы он сам печатал скобки и дефисы, маска делает это за него: он вводит `9111234567`, а в поле отображается `+7 (911) 123-45-67`.

---

### Зачем это нужно?

1. **UX (Пользовательский опыт):** Пользователю не нужно искать спецсимволы на клавиатуре.
    
2. **Валидация:** Маска не дает ввести лишние символы или буквы там, где должны быть цифры.
    
3. **Единообразие данных:** На сервер всегда улетают данные в одном и том же формате.
    

---

### 1. Добавление зависимости

Сначала добавь библиотеку в свой `build.gradle` (module: app):

Gradle

```
dependencies {
    implementation 'com.redmadrobot:input-mask-android:6.1.0'
}
```

### 2. Использование в коде (Kotlin)

Самый простой способ — создать слушатель маски и прикрепить его к твоему `EditText`.

Kotlin

```
class MainActivity : AppCompatActivity() {

    // Инициализируем биндинг
    private lateinit var binding: ActivityMainBinding

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        
        // Создаем объект биндинга
        binding = ActivityMainBinding.inflate(layoutInflater)
        setContentView(binding.root)


        MaskedTextChangedListener.installOn(
            binding.editTextPhone, // Обращаемся напрямую через binding
            "+7 ([000]) [000]-[00]-[00]",
            object : MaskedTextChangedListener.ValueListener {
                override fun onTextChanged(maskFilled: Boolean, extractedValue: String, formattedValue: String) {
                    // Логика обработки текста
                    if (maskFilled) {
                        binding.btnSend.isEnabled = true // Включаем кнопку через биндинг
                    }
                }
            }
        )
    }
}
```

### 3. Основные символы маски

Для своих заметок в Obsidian можешь выписать эти правила:

- `[0]` — любая обязательная цифра (0-9).
    
- `[9]` — необязательная цифра.
    
- `[a]` — любая обязательная буква.
    
- `[_]` — любой символ.
